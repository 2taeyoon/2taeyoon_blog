## Overview

Blue Orbit는 여러 정보가 하나의 중심을 따라 순환하도록 만든 공간형 탐색 경험입니다.

## Challenge

공간적인 움직임을 사용하면서도 사용자가 현재 선택된 항목과 전체 항목 수를 항상 이해할 수 있어야 했습니다.

## Approach

- 선택 상태와 위치 계산을 하나의 데이터 인덱스로 통합
- 시각적 배치와 별개로 논리적인 문서 순서 유지
- 화면 밖 요소의 렌더링 작업과 효과 최소화

## Key Features

### Spatial navigation

항목을 이동할 때 중심, 방향, 남은 거리를 시각적으로 전달해 연속적인 탐색 감각을 만들었습니다.

### Predictable controls

드래그와 버튼 선택이 같은 상태를 갱신하도록 구성해 입력 방식에 따른 결과 차이를 없앴습니다.

## Outcome

실험적인 공간 UI에서도 예측 가능한 상태와 접근 가능한 탐색 구조가 우선되어야 한다는 기준을 확립했습니다.
