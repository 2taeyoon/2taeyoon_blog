## Overview

Gilded Smoke는 어두운 공간 안에서 빛과 깊이를 표현하면서도 콘텐츠가 중심에 남도록 설계한 포트폴리오 실험입니다.

## Challenge

다층 효과와 큰 이미지를 사용하면서 초기 로딩과 스크롤 반응성을 안정적으로 유지해야 했습니다.

## Approach

- 화면에 보이는 요소만 높은 품질로 렌더링
- 이미지 크기와 브라우저 표시 영역에 맞는 리소스 제공
- 반복 계산과 불필요한 상태 업데이트 제거

## Key Features

### Layered composition

배경, 표면, 콘텐츠를 독립적인 레이어로 구성해 각 효과의 강도를 쉽게 조절할 수 있도록 했습니다.

### Performance budget

프레임마다 필요한 작업을 구분하고 정적인 계산은 렌더링 루프 밖에서 처리했습니다.

## Outcome

풍부한 시각 효과를 유지하면서도 성능을 정량적인 제약으로 다루는 제작 방식을 정리했습니다.
