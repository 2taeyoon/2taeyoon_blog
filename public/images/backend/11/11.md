## 🦮 목록·상세 화면에 썸네일 넣기(전체 흐름)

관리자 페이지에서 등록한 썸네일 이미지가 사용자 화면(목록, 상세)에 나오게 만들려면  
<strong>등록 → 데이터 붙이기 → 화면 출력</strong> 이 세 단계를 맞춰 주면 됩니다.

아래에서는 행사/이벤트 같은 목록을 예로 들어,  
어느 부분을 손봐야 하는지, 각 단계가 어떤 역할을 하는지 정리해 보겠습니다.

---

## 🦮 먼저 용어부터 정리하기

> 💡 <strong>미리 알아두면 좋은 말들</strong>  
> - <strong>썸네일</strong> : 목록이나 상세에서 보여 줄 대표 이미지 한 장  
> - <strong>파일 번호(SEQ)</strong> : 업로드된 파일을 DB에서 구분하는 고유 번호  
>   - “이 항목의 썸네일은 몇 번 파일이다”만 저장해 둡니다.  
> - <strong>컨트롤러</strong> : 목록/상세 데이터를 가져올 때 썸네일 정보도 같이 붙여 주는 서버 쪽 처리  
> - <strong>뷰(화면)</strong> : 붙어 온 썸네일 정보를 가지고 실제로 <code>&lt;img&gt;</code> 태그를 그리는 부분

구현 자체는 단순합니다.  
핵심은 <strong>관리자에서 파일 번호를 저장하고 → 컨트롤러에서 파일 정보를 붙이고 → 뷰에서 조건부로 출력한다</strong>  
이 흐름만 지켜 주는 것입니다.

---

## 🦮 1. 관리자 페이지 – 썸네일 등록

먼저 “이 항목(행사/이벤트)의 대표 이미지는 이 파일이다”를 관리자가 지정할 수 있어야 합니다.

<img src="/images/backend/11/main_image.webp"/>

### 🦄 하는 일 (쉽게 말하면)

- 관리자가 항목 등록·수정 화면에서 <strong>썸네일 이미지</strong>를 업로드합니다.  
- 업로드된 이미지는 <strong>파일 테이블</strong>에 저장되고, 그 파일의 <strong>고유 번호</strong>만 항목 테이블의 “썸네일 번호” 컬럼에 저장합니다.  
- 결국 DB에는 <strong>“이 항목의 썸네일 = 파일 번호 N번”</strong> 정보만 두고,  
  실제 파일 경로나 이름은 나중에 파일 테이블에서 조회해서 사용합니다.

### 🦄 화면에서 필요한 것

- 파일 선택 input (또는 공통 파일 업로드 컴포넌트)  
- 목록 타입에 따라 “썸네일 입력란을 보일지 말지”를 제어할 수 있으면 좋습니다.  
  - 예: 목록 타입이 “썸네일 있는 목록”일 때만 썸네일 업로드 필드 노출

### 🦄 DB 쪽

- 항목 테이블에 <strong>썸네일 파일 번호</strong>를 저장하는 컬럼 하나 (예: <code>thumb_seq</code>)  
- 파일 테이블에는 기존처럼 파일 경로, 파일명, 용량 등 파일 정보가 들어 있습니다.

---

## 🦮 2. 컨트롤러 – 목록/상세에 썸네일 데이터 붙이기

목록을 가져오거나 상세 한 건을 가져온 <strong>직후</strong>에  
“썸네일 번호가 있으면 → 그 번호로 파일 정보 조회 → 각 항목(또는 상세 데이터)에 넣어 둔다”는 처리를 해 줍니다.

<img src="/images/backend/11/images1.webp"/>

### 🦄 목록일 때

목록은 여러 건이 있으니, 각 항목을 돌면서 썸네일 번호가 있는지 확인하고,  
있을 때만 파일 정보를 조회해 붙이는 구조로 보시면 됩니다.

```php
// 예: 목록 조회 직후
$list = $this->itemModel->selectAll($param);

foreach ($list as $k => $v) {
    if (!empty($v['thumb_seq'])) {
        $list[$k]['thumbnailFile'] = $this->itemModel->selectFileBySeq($v['thumb_seq']);
    }
}

// 이제 $list를 뷰에 넘김
```

### 🦄 한 줄씩 이해하기

1. <strong><code>$list = ... selectAll(...)</code></strong>  
   - 목록 데이터를 DB에서 가져옵니다. 각 행에는 <code>thumb_seq</code>(썸네일 파일 번호)가 있을 수 있습니다.
2. <strong><code>foreach ($list as $k =&gt; $v)</code></strong>  
   - 목록의 항목을 하나씩 봅니다.
3. <strong><code>if (!empty($v['thumb_seq']))</code></strong>  
   - 이 항목에 썸네일 번호가 있을 때만 파일 조회를 합니다. 없으면 건너뜁니다.
4. <strong><code>selectFileBySeq($v['thumb_seq'])</code></strong>  
   - “이 번호에 해당하는 파일 정보(경로, 파일명 등)”를 DB에서 가져오는 모델 메서드라고 보면 됩니다.
5. <strong><code>$list[$k]['thumbnailFile'] = ...</code></strong>  
   - 가져온 파일 정보를 <strong>그 항목에만</strong> 넣어 둡니다.  
     나중에 뷰에서는 <code>$row['thumbnailFile']</code>로 접근해서 이미지 주소를 만들 수 있습니다.

### 🦄 상세일 때

상세는 한 건만 보므로, 반복문 없이 한 번만 조회해서 붙이면 충분합니다.

```php
// 예: 상세 한 건 조회 직후
$data = $this->itemModel->selectRow($id);

if (!empty($data['thumb_seq'])) {
    $data['thumbnailFile'] = $this->itemModel->selectFileBySeq($data['thumb_seq']);
}

// 이제 $data를 뷰에 넘김
```

### 🦄 Ajax로 목록을 불러올 때

목록을 <strong>페이지 이동 없이 Ajax</strong>로 받아 오는 경우에도 마찬가지입니다.  
서버에서 목록 배열을 만든 직후에 위와 같은 <code>foreach</code>로 각 항목에 <code>thumbnailFile</code>을 붙여 주어야,  
클라이언트로 넘어가는 JSON 안에 썸네일 정보가 포함됩니다.

> 👉 <strong>정리</strong>  
> “목록/상세를 가져오는 곳” 바로 다음에  
> <strong>썸네일 번호가 있으면 파일 정보를 조회해서 <code>thumbnailFile</code>에 넣어 준다</strong>  
> 이 한 줄만 기억해 두면 됩니다.

---

## 🦮 3. 목록 화면 – 썸네일 출력

컨트롤러에서 <code>thumbnailFile</code>을 붙여 주었다면,  
목록 뷰에서는 “파일 정보가 있을 때만” 이미지 태그를 출력해 주면 됩니다.

<img src="/images/backend/11/images2.webp"/>

### 🦄 하는 일 (쉽게 말하면)

- 각 목록 항목마다 “썸네일 파일 정보가 있나?” 확인합니다.  
- 있으면 <code>&lt;div&gt;</code> + <code>&lt;img&gt;</code>로 이미지를 보여 주고,  
  이미지 주소는 <strong>파일 번호(또는 파일명)를 넘겨서 이미지를 출력하는 공통 URL</strong>을 사용합니다.  
  - 예: <code>image.php?f=파일명&amp;s=파일번호</code>  
- 없으면 아무 것도 출력하지 않습니다.

### 🦄 예시 (목록 한 행 = <code>$row</code>)

```html
<!-- 목록 한 항목 안, 제목/내용 앞에 넣는 경우 -->
<div class="list-item">
    <?php if (!empty($row['thumbnailFile']['seq'])) : ?>
    <div class="item-thumb">
        <img src="/libs/image.php?f=<?= $row['thumbnailFile']['fileName'] ?>&s=<?= $row['thumbnailFile']['seq'] ?>"
             alt="<?= $row['title'] ?>">
    </div>
    <?php endif; ?>
    <div class="item-body">
        <h4><?= $row['title'] ?></h4>
        ...
    </div>
</div>
```

### 🦄 읽는 방법

- <strong><code>$row['thumbnailFile']['seq']</code></strong>  
  컨트롤러에서 붙여 준 파일 정보입니다. <code>seq</code>(파일 번호), <code>fileName</code>(파일명) 등이 있다고 가정합니다.
- <strong><code>image.php?f=...&amp;s=...</code></strong>  
  실제 이미지를 출력하는 공통 스크립트입니다.  
  <code>f</code>=파일명, <code>s</code>=파일 번호처럼 넘기면, 서버가 해당 파일을 읽어 브라우저에 내보냅니다.
- <strong>alt</strong>  
  이미지 로딩 실패 시 대체 텍스트입니다. 제목을 넣어 두면 접근성에도 도움이 됩니다.

---

## 🦮 4. 상세 화면 – 썸네일 출력

상세는 “한 건”이므로 <code>$data</code> 하나만 다루면 됩니다.  
구조는 목록과 거의 같습니다.

### 🦄 예시 (상세 한 건 = <code>$data</code>)

```html
<!-- 제목 아래, 본문 위에 넣는 경우 -->
<h1><?= $data['title'] ?></h1>

<?php if (!empty($data['thumbnailFile']['seq'])) : ?>
<div class="detail-thumb mb20">
    <img src="/libs/image.php?f=<?= $data['thumbnailFile']['fileName'] ?>&s=<?= $data['thumbnailFile']['seq'] ?>"
         alt="<?= $data['title'] ?>">
</div>
<?php endif; ?>

<div class="content">
    ...
</div>
```

### 🦄 목록과의 차이

- 목록: <code>$row</code>를 반복하면서 각각 <code>$row['thumbnailFile']</code> 사용  
- 상세: <code>$data</code> 한 번만, <code>$data['thumbnailFile']</code> 사용  
- 나머지(있을 때만 출력, <code>image.php</code> 주소 조합)는 동일합니다.

---

## 🦮 전체 흐름 요약

1. <strong>관리자</strong>가 항목 등록·수정 화면에서 썸네일 이미지를 선택해 올립니다.  
   - 파일 테이블에 파일 정보가 저장되고, 항목 테이블에는 “썸네일 파일 번호”만 저장됩니다.
2. <strong>사용자가 목록/상세 페이지를 열면</strong>  
   - 컨트롤러가 목록(또는 상세 한 건)을 DB에서 가져옵니다.
3. <strong>컨트롤러</strong>가 썸네일 번호가 있는 항목에 대해 파일 정보를 조회해 <code>thumbnailFile</code>에 넣어 줍니다.
4. <strong>뷰</strong>는 <code>thumbnailFile</code>이 있을 때만 <code>&lt;img&gt;</code>를 출력하고,  
   이미지 주소는 <code>image.php</code> 같은 공통 URL에 파일명·파일 번호를 넘겨서 만듭니다.
5. 최종적으로 사용자 화면의 목록/상세에 썸네일이 노출됩니다.

---

## 🦮 이 구조의 장점

- <strong>역할이 명확하게 나뉩니다</strong>  
  - 등록은 관리자 화면, “데이터 붙이기”는 컨트롤러, “보여 주기”는 뷰 역할입니다.  
  - 나중에 “썸네일 크기만 바꾸고 싶다” → 뷰/CSS만,  
    “썸네일 조회 조건을 바꾸고 싶다” → 컨트롤러/모델만 수정하면 됩니다.
- <strong>썸네일이 없는 항목도 안전합니다</strong>  
  - <code>if (!empty(...))</code>로 감싸 두면, 썸네일이 없어도 이미지 영역을 그리지 않아서 레이아웃이 깨지지 않습니다.
- <strong>다른 목록에도 재사용할 수 있습니다</strong>  
  - “파일 번호 하나 저장 → 파일 정보 조회 → <code>thumbnailFile</code> 붙이기 → 뷰에서 <code>&lt;img&gt;</code> 출력” 패턴을  
    상품 목록, 게시글 목록 등 다른 모듈에도 그대로 복사해 쓸 수 있습니다.

---

## 🦮 마무리

목록·상세에 썸네일을 넣는 일은 결국 세 단계로 정리할 수 있습니다.

1. <strong>관리자</strong>가 “썸네일 파일 번호”를 저장하고  
2. <strong>컨트롤러</strong>가 그 번호로 파일 정보를 조회해 각 항목(또는 상세 데이터)에 붙이고  
3. <strong>뷰</strong>가 그 정보가 있을 때만 이미지 태그를 출력합니다.

이 흐름만 잡아 두면, 행사/이벤트뿐 아니라  
상품 목록, 게시글 목록 등 다양한 목록 화면에도 같은 방식으로 썸네일을 붙일 수 있습니다.
