## 🦮 1. 클래스와 객체

마린이나 탱크는 이름, 체력, 공격력을 가진 같은 종류의 유닛입니다. 그 공통점을 적어 둔 설계도가 클래스이고, 설계도로 찍어 낸 실제 하나하나가 객체입니다. 마린이 세 명이어도 설계도는 하나이고, 객체는 세 개입니다.

```python
name = "마린"
hp = 40
damage = 5

print("{0} 유닛이 생성되었습니다.".format(name))
print("체력 {0}, 공격력 {1}\n".format(hp, damage))

tank_name = "탱크"
tank_hp = 150
tank_damage = 35

print("{0} 유닛이 생성되었습니다.".format(tank_name))
print("체력 {0}, 공격력 {1}\n".format(tank_hp, tank_damage))

def attack(name, location, damage):
    print("{0} : {1} 방향으로 적군을 공격 합니다. [공격력 {2}]".format(name, location, damage))

attack(name, "1시", damage)
attack(tank_name, "1시", tank_damage)
```

유닛이 늘어날 때마다 변수 이름이 `tank_name`, `tank2_name`처럼 늘어납니다. 클래스에 넣으면 설계는 한 번만 적고, 객체만 더 만들면 됩니다.

```python
class Unit:
    def __init__(self, name, hp, damage):
        self.name = name
        self.hp = hp
        self.damage = damage
        print("{0} 유닛이 생성되었습니다.".format(self.name))
        print("체력 {0}, 공격력 {1}".format(self.hp, self.damage))

marine1 = Unit("마린", 40, 5)
marine2 = Unit("마린", 40, 5)
tank = Unit("탱크", 150, 35)
```

`marine1`과 `marine2`는 같은 클래스에서 나왔지만 서로 다른 객체입니다. 한쪽의 체력을 나중에 바꿔도 다른 쪽은 그대로입니다.

## 🦮 2. __init__

`__init__`은 객체를 만드는 순간 자동으로 호출됩니다. `Unit("마린", 40, 5)`라고 적으면 이 세 값이 `__init__`의 `name`, `hp`, `damage`로 들어갑니다. 직접 `marine1.__init__()`을 호출하지 않습니다.

`self`는 지금 만들어지는 그 객체입니다. `self.name = name`은 전달받은 이름을 이 객체 안에 저장한다는 뜻입니다. 필요한 인자를 빠뜨리면 객체가 만들어지지 않고 오류가 납니다.

```python
class Unit:
    def __init__(self, name, hp, damage):
        self.name = name
        self.hp = hp
        self.damage = damage
        print("{0} 유닛이 생성 되었습니다.".format(self.name))
        print("체력 {0}, 공격력 {1}".format(self.hp, self.damage))

marine1 = Unit("마린", 40, 5)
marine2 = Unit("마린", 40, 5)
tank = Unit("탱크", 150, 35)
```

`Unit("마린", 40)`처럼 공격력을 빼먹으면 `TypeError`가 납니다. `__init__`이 요구하는 값을 객체가 태어날 때 모두 받아야 합니다.

## 🦮 3. 멤버변수

클래스 안에서 `self.`로 붙여 둔 변수는 그 객체마다 따로 가지는 멤버변수입니다. 객체 밖에 나와서도 점으로 읽거나 고칠 수 있습니다.

```python
wraith1 = Unit("레이스", 80, 5)
print("유닛 이름 : {0}, 공격력 : {1}".format(wraith1.name, wraith1.damage))

wraith2 = Unit("빼앗은 레이스", 80, 5)
wraith2.clocking = True

if wraith2.clocking == True:
    print("{0} 는 현재 클로킹 상태입니다.".format(wraith2.name))
```

`clocking`은 클래스 안에 없던 변수입니다. `wraith2.clocking = True`는 그 객체에만 멤버를 추가합니다. `wraith1.clocking`을 읽으면 그 객체에는 변수가 없어서 오류가 납니다. 모든 객체가 가져야 하는 값은 `__init__`에서 만드는 편이 안전합니다.

## 🦮 4. 메소드

메소드는 클래스 안에 들어 있는 함수입니다. 첫 인자는 `self`입니다. 호출할 때는 `self`를 적지 않습니다. `firebat.attack("5시")`에서 `firebat`이 `self`가 됩니다.

공격 위치는 유닛이 태어날 때 정해져 있지 않습니다. 공격하는 순간에 받으므로 `location`은 `__init__`이 아니라 `attack`의 인자입니다.

```python
class AttackUnit:
    def __init__(self, name, hp, damage):
        self.name = name
        self.hp = hp
        self.damage = damage

    def attack(self, location):
        print("{0} : {1} 방향으로 적군을 공격 합니다. [공격력 {2}]".format(self.name, location, self.damage))

    def damaged(self, damage):
        print("{0} : {1} 데미지를 입었습니다.".format(self.name, damage))
        self.hp -= damage
        print("{0} : 현재 체력은 {1} 입니다.".format(self.name, self.hp))

firebat1 = AttackUnit("파이어뱃", 50, 16)
firebat1.attack("5시")

firebat1.damaged(25)
firebat1.damaged(25)
```

`attack`은 멤버변수 `self.damage`를 읽고, 인자 `location`은 이번 호출에서만 씁니다. `damaged`는 받은 피해만큼 `self.hp`를 줄입니다. 두 번 맞으면 체력이 50에서 25, 다시 0이 됩니다.

일반 함수와 메소드의 차이는 소속입니다. 함수는 혼자 호출되고, 메소드는 어떤 객체가 그 일을 하는지가 앞에 붙습니다.

## 🦮 5. 상속

공격 유닛도 이름과 체력이 있습니다. `Unit`에 이미 있는 초기화를 `AttackUnit`에 다시 적지 않고 물려받습니다. 괄호 안에 적는 클래스가 부모이고, 물려받는 쪽이 자식입니다.

부모 `__init__`을 호출해야 부모 쪽 멤버변수가 생깁니다. 자식은 공격력만 추가로 가집니다. 메소드 `attack`과 `damaged`도 자식에 정의하면, 부모의 이름과 체력을 그대로 사용합니다.

```python
class Unit:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

class AttackUnit(Unit):
    def __init__(self, name, hp, damage):
        Unit.__init__(self, name, hp)
        self.damage = damage

    def attack(self, location):
        print("{0} : {1} 방향으로 적군을 공격 합니다. [공격력 {2}]".format(self.name, location, self.damage))

    def damaged(self, damage):
        print("{0} : {1} 데미지를 입었습니다.".format(self.name, damage))
        self.hp -= damage
        print("{0} : 현재 체력은 {1} 입니다.".format(self.name, self.hp))

firebat1 = AttackUnit("파이어뱃", 50, 16)
firebat1.attack("5시")
firebat1.damaged(25)
```

`Unit.__init__(self, name, hp)`에서 `self`는 지금 만들고 있는 `AttackUnit` 객체입니다. 부모 초기화에 이 객체를 넘겨, `name`과 `hp`를 그 객체에 붙입니다.

메딕처럼 치료만 하는 유닛은 공격력이 없으므로 `AttackUnit`이 아니라 `Unit`으로 만들면 됩니다.

```python
class Medic(Unit):
    def __init__(self, name, hp):
        Unit.__init__(self, name, hp)

medic1 = Medic("메딕", 60)
print(medic1.name, medic1.hp)
```

## 🦮 6. 다중 상속

날아다니는 능력은 공격과 별개입니다. 드랍십은 날지만 공격이 없고, 발키리는 날면서 공격합니다. 비행을 다른 클래스로 분리한 뒤, 필요한 클래스만 함께 물려받습니다. 괄호 안에 클래스를 쉼표로 나열하면 다중 상속입니다.

```python
class Flyable:
    def __init__(self, flying_speed):
        self.flying_speed = flying_speed

    def fly(self, name, location):
        print("{0} : {1} 방향으로 날아갑니다. [속도 {2}]".format(name, location, self.flying_speed))

class FlyableAttackUnit(AttackUnit, Flyable):
    def __init__(self, name, hp, damage, flying_speed):
        AttackUnit.__init__(self, name, hp, damage)
        Flyable.__init__(self, flying_speed)

valkyrie = FlyableAttackUnit("발키리", 200, 6, 5)
valkyrie.fly(valkyrie.name, "3시")
```

발키리는 공격 유닛의 `attack`, `damaged`와 비행 클래스의 `fly`를 모두 가집니다. 부모를 각각 `__init__`으로 호출해야 체력과 비행 속도가 둘 다 생깁니다. 한쪽만 호출하면 나머지 멤버가 없습니다.

## 🦮 7. 메소드 오버라이딩

영상 표지와 일부 설명에는 이 구간이 “연산자 오버로딩”이라고 되어 있습니다. 실제로 하는 일은 <strong>메소드 오버라이딩</strong>입니다. 부모와 같은 이름의 메소드를 자식에 다시 정의하면, 그 객체는 자식 쪽 동작을 사용합니다.

지상 유닛은 `move`로 걸어가고, 공중 유닛도 바깥에서는 `move`로 이동시키고 싶습니다. 공중 유닛의 `move`를 다시 정의해서, 안에서는 `fly`를 호출하게 만듭니다.

```python
class Unit:
    def __init__(self, name, hp, speed):
        self.name = name
        self.hp = hp
        self.speed = speed

    def move(self, location):
        print("[지상 유닛 이동]")
        print("{0} : {1} 방향으로 이동합니다. [속도 {2}]".format(self.name, location, self.speed))

class AttackUnit(Unit):
    def __init__(self, name, hp, speed, damage):
        Unit.__init__(self, name, hp, speed)
        self.damage = damage

    def attack(self, location):
        print("{0} : {1} 방향으로 적군을 공격 합니다. [공격력 {2}]".format(self.name, location, self.damage))

    def damaged(self, damage):
        print("{0} : {1} 데미지를 입었습니다.".format(self.name, damage))
        self.hp -= damage
        print("{0} : 현재 체력은 {1} 입니다.".format(self.name, self.hp))

class Flyable:
    def __init__(self, flying_speed):
        self.flying_speed = flying_speed

    def fly(self, name, location):
        print("{0} : {1} 방향으로 날아갑니다. [속도 {2}]".format(name, location, self.flying_speed))

class FlyableAttackUnit(AttackUnit, Flyable):
    def __init__(self, name, hp, damage, flying_speed):
        AttackUnit.__init__(self, name, hp, 0, damage)
        Flyable.__init__(self, flying_speed)

    def move(self, location):
        print("[공중 유닛 이동]")
        self.fly(self.name, location)

vulture = AttackUnit("벌쳐", 80, 10, 20)
vulture.move("11시")

battlecruiser = FlyableAttackUnit("배틀크루저", 500, 25, 3)
battlecruiser.move("9시")
```

벌쳐는 지상 유닛이라 부모 `move`가 실행되고 속도 10이 출력됩니다. 배틀크루저는 자식이 `move`를 다시 적었으므로 `[공중 유닛 이동]`이 나오고 `fly`가 실행됩니다. 호출하는 쪽은 둘 다 `.move("방향")`입니다. 지상인지 공중인지에 따라 실제 동작이 달라집니다.

공중 유닛의 지상 속도는 0으로 넣습니다. 이동은 `flying_speed`로 하기 때문입니다.

## 🦮 8. pass

본문을 아직 적지 않았는데 문법상 비워 둘 수 없을 때 `pass`를 넣습니다. 자리를 차지할 뿐 아무 일도 하지 않습니다.

```python
class BuildingUnit(Unit):
    def __init__(self, name, hp, location):
        pass

supply_depot = BuildingUnit("서플라이 디폿", 500, "7시")
```

`pass`가 없으면 클래스 본문이 비어 오류가 납니다. 함수나 `if` 본문에도 같은 용도로 씁니다. 나중에 건물의 실제 동작을 채우기 전까지 이름만 예약해 두는 자리입니다.

```python
def game_start():
    print("[알림] 새로운 게임을 시작합니다.")

def game_over():
    pass

game_start()
game_over()
```

## 🦮 9. super

부모가 하나이면 `super().__init__()`로 부모 초기화를 호출할 수 있습니다. 이때는 `self`를 직접 넘기지 않습니다.

```python
class BuildingUnit(Unit):
    def __init__(self, name, hp, location):
        super().__init__(name, hp, 0)
        self.location = location
```

부모가 둘 이상이면 주의가 필요합니다. 영상에서는 `super()`가 맨 마지막 부모를 호출한다고 말하지만, 실제로는 <strong>괄호에 먼저 적은 부모</strong>만 초기화됩니다.

```python
class FlyableUnit(Flyable, Unit):
    def __init__(self):
        super().__init__(1)
```

이 예제는 `Flyable`이 먼저이므로 `Flyable.__init__(flying_speed)`가 호출되고, 인자 1은 비행 속도로 들어갑니다. `Unit`의 이름과 체력은 초기화되지 않습니다. 두 부모를 모두 초기화하려면 `Flyable.__init__`과 `Unit.__init__`을 각각 부르는 편이 분명합니다.

```python
class FlyableUnit(Flyable, Unit):
    def __init__(self):
        Flyable.__init__(self, 1)
        Unit.__init__(self, "비행유닛", 100, 0)
```

## 🦮 10. 스타크래프트 전반전

지금까지의 클래스를 유닛 종류로 나눕니다. 마린과 탱크는 공격 유닛을 물려받고, 각자 `__init__` 안에서 이름과 능력치를 고정합니다. 만들 때 인자를 넘기지 않아도 마린은 항상 체력 40, 이동 속도 1, 공격력 5입니다.

마린은 스팀팩을 쓰면 체력 10을 잃고 공격 속도가 빨라진다고 출력합니다. 체력이 10 이하면 쓰지 못합니다. 탱크의 시즈모드는 클래스 변수로 “개발되었는지”를 공유합니다. `Tank.seize_developed`는 탱크 객체마다 있는 값이 아니라, 탱크 종류 전체가 공유하는 값입니다.

```python
class Marine(AttackUnit):
    def __init__(self):
        AttackUnit.__init__(self, "마린", 40, 1, 5)

    def stimpack(self):
        if self.hp > 10:
            self.hp -= 10
            print("{0} : 스팀팩을 사용합니다. (HP 10 감소)".format(self.name))
        else:
            print("{0} : 체력이 부족하여 스팀팩을 사용하지 않습니다.".format(self.name))

class Tank(AttackUnit):
    seize_developed = False

    def __init__(self):
        AttackUnit.__init__(self, "탱크", 150, 1, 35)
        self.seize_mode = False

    def set_seize_mode(self):
        if Tank.seize_developed == False:
            return

        if self.seize_mode == False:
            print("{0} : 시즈모드로 전환합니다.".format(self.name))
            self.damage *= 2
            self.seize_mode = True
        else:
            print("{0} : 시즈모드를 해제합니다.".format(self.name))
            self.damage /= 2
            self.seize_mode = False
```

시즈모드가 개발되기 전에 `set_seize_mode`를 호출하면 `return`으로 바로 빠져나옵니다. 개발된 뒤에는 호출할 때마다 켜짐과 꺼짐이 뒤집히고, 공격력은 두 배가 되었다가 다시 절반이 됩니다.

레이스는 공중 공격 유닛입니다. 클로킹은 객체마다 다른 상태라 `self.clocked`에 둡니다. 메소드를 호출할 때마다 참과 거짓이 바뀝니다.

```python
class Wraith(FlyableAttackUnit):
    def __init__(self):
        FlyableAttackUnit.__init__(self, "레이스", 80, 20, 5)
        self.clocked = False

    def clocking(self):
        if self.clocked == True:
            print("{0} : 클로킹 모드 해제합니다.".format(self.name))
            self.clocked = False
        else:
            print("{0} : 클로킹 모드 설정합니다.".format(self.name))
            self.clocked = True
```

## 🦮 11. 스타크래프트 후반전

게임을 시작하고, 유닛을 만든 뒤, 공격과 피해를 주고, 끝나면 퇴장 문장을 출력합니다. 이동은 지상과 공중 모두 `move`를 호출합니다. 공중 유닛은 오버라이딩된 `move`가 `fly`를 실행합니다.

```python
def game_start():
    print("[알림] 새로운 게임을 시작합니다.")

def game_over():
    print("Player : gg")
    print("[Player] 님이 게임에서 퇴장하셨습니다.")

game_start()

m1 = Marine()
m2 = Marine()
m3 = Marine()

t1 = Tank()
t2 = Tank()

w1 = Wraith()

attack_units = []
attack_units.append(m1)
```

```python
damage = randint(5, 20)
```

## 🦮 13. 예외 처리

없는 값을 숫자로 바꾸거나, 0으로 나누거나, 없는 인덱스를 읽으면 그 줄에서 프로그램이 멈춥니다. `try` 안에 위험할 수 있는 코드를 넣고, `except`에서 어떻게 알릴지 적습니다. 예외 종류를 나누면 원인에 맞는 문장을 보여줄 수 있습니다.

```python
try:
    print("나누기 전용 계산기입니다.")
    nums = []
    nums.append(int(input("첫 번째 숫자를 입력하세요 : ")))
    nums.append(int(input("두 번째 숫자를 입력하세요 : ")))
    nums.append(int(nums[0] / nums[1]))
    print("{0} / {1} = {2}".format(nums[0], nums[1], nums[2]))
except ValueError:
    print("에러! 잘못된 값을 입력하였습니다.")
except ZeroDivisionError as err:
    print(err)
except Exception as err:
    print("알 수 없는 에러가 발생하였습니다.")
    print(err)
```

글자를 입력하면 `int()`가 `ValueError`를 냅니다. 두 번째 숫자가 0이면 `ZeroDivisionError`입니다. `as err`는 그 오류 객체를 변수로 받아 기본 메시지를 출력합니다.

인덱스를 일부러 틀리면 다른 예외가 납니다. 예를 들어 나눗셈 결과를 `nums[2]`에 넣지 않고 `nums[2]`를 읽으면 `IndexError`입니다. 위에서 잡지 않은 예외는 마지막 `Exception`이 받습니다. `Exception`은 대부분 오류의 부모라, 구체적인 `except`보다 아래에 두어야 합니다. 위에 두면 모든 오류를 먼저 가져가 버립니다.

오류가 없을 때만 이어서 할 일은 `else`에 적습니다.

```python
try:
    print("한 자리 숫자 나누기 전용 계산기입니다.")
    num1 = int(input("첫 번째 숫자를 입력하세요 : "))
    num2 = int(input("두 번째 숫자를 입력하세요 : "))
    if num1 >= 10 or num2 >= 10:
        raise ValueError
    print("{0} / {1} = {2}".format(num1, num2, int(num1 / num2)))
except ValueError:
    print("잘못된 값을 입력하였습니다. 한 자리 숫자만 입력하세요.")
else:
    print("계산이 정상적으로 끝났습니다.")
```

`else`는 예외가 없을 때만 실행됩니다. `except`로 빠지면 `else`는 실행되지 않습니다.

## 🦮 14. 에러 발생시키기

조건은 문법적으로 맞지만 우리 규칙에는 어긋날 때 `raise`로 예외를 일부러 발생시킵니다. 한 자리 숫자만 허용하는데 10 이상이 들어오면 `ValueError`를 일으켜, 위의 `except`가 받게 합니다.

```python
try:
    print("한 자리 숫자 나누기 전용 계산기입니다.")
    num1 = int(input("첫 번째 숫자를 입력하세요 : "))
    num2 = int(input("두 번째 숫자를 입력하세요 : "))
    if num1 >= 10 or num2 >= 10:
        raise ValueError
    print("{0} / {1} = {2}".format(num1, num2, int(num1 / num2)))
except ValueError:
    print("잘못된 값을 입력하였습니다. 한 자리 숫자만 입력하세요.")
```

`raise`가 없으면 10 이상도 그냥 나눗셈이 됩니다. `raise`를 만나면 그 아래 `print`는 실행되지 않고 `except`로 건너뜁니다.

## 🦮 15. 사용자 정의 예외

기본 예외의 이름만으로는 이유가 드러나지 않을 때, `Exception`을 물려받아 예외 클래스를 만듭니다. 메시지 형식을 직접 붙이고 싶으면 `__str__`을 정의합니다. `__str__`이 없어도 생성자에 넣은 메시지는 출력되지만, 에러 코드처럼 앞뒤를 붙이려면 `__str__`이 필요합니다.

```python
class BigNumberError(Exception):
    def __init__(self, msg):
        self.msg = msg

    def __str__(self):
        return "[에러코드 001] " + self.msg

try:
    print("한 자리 숫자 나누기 전용 계산기입니다.")
    num1 = int(input("첫 번째 숫자를 입력하세요 : "))
    num2 = int(input("두 번째 숫자를 입력하세요 : "))
    if num1 >= 10 or num2 >= 10:
        raise BigNumberError("입력값 : {0}, {1}".format(num1, num2))
    print("{0} / {1} = {2}".format(num1, num2, int(num1 / num2)))
except ValueError:
    print("잘못된 값을 입력하였습니다. 한 자리 숫자만 입력하세요.")
except BigNumberError as err:
    print("에러가 발생하였습니다. 한 자리 숫자만 입력하세요.")
    print(err)
```

10 이상을 입력하면 `BigNumberError`가 발생하고, `print(err)`은 `[에러코드 001] 입력값 : ...` 형태로 나옵니다. 글자를 입력하면 여전히 `ValueError`입니다. 예외 클래스가 다르므로 `except`도 나뉩니다.

## 🦮 16. finally

`finally`는 오류가 있든 없든, `try`를 벗어나기 전에 반드시 실행됩니다. 계산기를 종료한다는 문장, 파일을 닫는 일처럼 빠지면 안 되는 마무리에 씁니다.

```python
class BigNumberError(Exception):
    def __init__(self, msg):
        self.msg = msg

    def __str__(self):
        return self.msg

try:
    print("한 자리 숫자 나누기 전용 계산기입니다.")
    num1 = int(input("첫 번째 숫자를 입력하세요 : "))
    num2 = int(input("두 번째 숫자를 입력하세요 : "))
    if num1 >= 10 or num2 >= 10:
        raise BigNumberError("입력값 : {0}, {1}".format(num1, num2))
    print("{0} / {1} = {2}".format(num1, num2, int(num1 / num2)))
except ValueError:
    print("잘못된 값을 입력하였습니다. 한 자리 숫자만 입력하세요.")
except BigNumberError as err:
    print("에러가 발생하였습니다. 한 자리 숫자만 입력하세요.")
    print(err)
finally:
    print("계산기를 이용해 주셔서 감사합니다.")
```

정상 계산이어도, `ValueError`여도, `BigNumberError`여도 마지막 감사 문장은 출력됩니다.

## 🦮 17. 퀴즈 9. 치킨 주문

치킨집에 치킨이 10마리 있습니다. 주문 수가 남긴 치킨보다 많으면 재고 소진 오류를 내고 주문을 멈춥니다. 1보다 작은 수나 글자는 잘못된 값으로 안내합니다. 주문이 성공하든 실패하든 마지막에 영업 종료 문장을 출력합니다.

```python
class SoldOutError(Exception):
    pass

chicken = 10
waiting = 1
while True:
    try:
        print("[남은 치킨 : {0}]".format(chicken))
        order = int(input("치킨 몇 마리 주문하시겠습니까? "))
        if order > chicken:
            print("재료가 부족합니다.")
        elif order <= 0:
            raise ValueError
        else:
            print("[대기번호 {0}] {1} 마리 주문이 완료되었습니다.".format(waiting, order))
            waiting += 1
            chicken -= order
        if chicken == 0:
            raise SoldOutError
    except ValueError:
        print("잘못된 값을 입력하였습니다.")
    except SoldOutError:
        print("재고가 소진되어 더 이상 주문을 받지 않습니다.")
        break
    finally:
        print("영업을 마칩니다.")
```

`order <= 0`이면 `ValueError`를 일으켜 아래 `except`가 안내합니다. 남은 치킨보다 많이 시키면 주문은 들어가지 않고 재료 부족만 알립니다. 치킨이 0이 되는 주문 직후에 `SoldOutError`가 발생하고, `break`로 `while`을 빠져나옵니다. `finally`는 `break` 직전에도 실행되므로, 재고가 떨어져 루프를 끝내기 전에도 영업 종료 문장이 한 번 출력됩니다. 주문이 계속되는 동안에도 매번 `finally`가 실행됩니다.

## 🦮 18. 모듈

한 파일이 길어지면 기능별로 나눕니다. `theater_module.py`에 영화표 가격 함수를 적고, 다른 파일에서 불러옵니다. 두 파일은 같은 폴더에 둡니다.

```python
def price(people):
    print("{0}명 가격은 {1}원 입니다.".format(people, people * 10000))

    print("{0}명 조조 할인 가격은 {1}원 입니다.".format(people, people * 6000))
```

`import theater_module`로 가져오면, 함수 앞에 모듈 이름을 붙여 호출합니다.

```python
import theater_module

theater_module.price(3)
theater_module.price_morning(4)
theater_module.price_soldier(5)
```

이름이 길면 `as`로 별칭을 줍니다.

```python
import theater_module as mv
```

```python
from theater_module import *
```

```python
from theater_module import price_soldier as price
```

## 🦮 20. __all__

`from travel import *`는 패키지 안의 모듈을 한 번에 가져오려는 문장입니다. 공개할 모듈을 `__init__.py`의 `__all__` 목록에 적어야 들어옵니다. 목록에 없으면 `import *`로는 오지 않습니다. 모듈 이름을 직접 지정하면 목록과 관계없이 가져올 수 있습니다.

```python
__all__ = ["vietnam"]
```

```python
from travel import *

trip_to = vietnam.VietnamPackage()
trip_to.detail()
```

`thailand`는 `__all__`에 없으므로 `from travel import *` 뒤의 `thailand`는 정의되지 않았다고 나옵니다. `from travel.thailand import ThailandPackage`처럼 경로를 직접 적으면 가져올 수 있습니다.

## 🦮 21. 모듈을 직접 실행할 때

모듈 파일 맨 아래에 테스트 출력을 적어 두면, 다른 파일에서 `import`할 때도 그 출력이 실행됩니다. 파일을 직접 실행했을 때만 테스트를 돌리고 싶으면 `__name__`을 확인합니다.

이 파일을 직접 실행하면 `__name__`이 `"__main__"`입니다. 다른 파일에서 `import`하면 `__name__`은 모듈 이름 `"thailand"`가 되므로, 아래 테스트는 실행되지 않습니다.

```python
class ThailandPackage:
    def detail(self):
        print("[태국 패키지 3박 5일] 방콕, 파타야 여행 (야시장 투어) 50만원")

if __name__ == "__main__":
    print("Thailand 모듈을 직접 실행")
    print("이 문장은 모듈을 직접 실행할 때만 출력돼요")
    trip_to = ThailandPackage()
    trip_to.detail()
else:
    print("Thailand 외부에서 모듈 호출")
```

## 🦮 23. pip install

파이썬에 기본으로 없는 패키지는 `pip`로 설치합니다. 강의에서는 웹 페이지를 읽는 `beautifulsoup4`를 예로 듭니다. 설치 이름은 `beautifulsoup4`이고, 코드에서 불러오는 이름은 `bs4`입니다.

```bash
pip install beautifulsoup4
```

```python
from bs4 import BeautifulSoup

soup = BeautifulSoup("<p>Some<b>bad<i>HTML")
print(soup.prettify())
```

`prettify`는 엉킨 태그를 파이썬이 이해한 형태로 들여쓰기해 보여 줍니다.

설치했는데 `ModuleNotFoundError: No module named 'bs4'`가 나면, 터미널의 파이썬과 편집기가 쓰는 파이썬이 다른 경우가 많습니다. 터미널에서 `python -V`로 본 버전과 편집기 하단에 표시된 버전을 같은 것으로 맞춥니다.

`pip` 자체를 찾지 못하면, 설치할 때 PATH 추가가 빠져 있었을 수 있습니다. 그 경우는 파이썬을 다시 설치하면서 PATH 옵션을 켜거나, 환경변수에 파이썬과 `Scripts` 폴더를 직접 넣습니다.

설치한 목록은 `pip list`, 지울 때는 `pip uninstall beautifulsoup4`입니다. 버전을 고정하려면 `pip install beautifulsoup4==4.12.3`처럼 등호 뒤에 버전을 붙입니다. 지금 깔린 버전은 `pip show beautifulsoup4`로 확인합니다.

## 🦮 24. 내장 함수

따로 `import`하지 않아도 쓸 수 있는 함수가 내장 함수입니다. `input`, `print`, `int`, `str`, `len`, `range`, `max`, `min`, `round`, `type`, `enumerate`, `zip`이 여기 속합니다.

```python
language = input("무슨 언어를 좋아하세요? ")
print("{0}은 아주 좋은 언어입니다!".format(language))
```

`dir()`은 지금 쓸 수 있는 이름 목록을 보여 줍니다. 인자가 없으면 현재 파일에서 보이는 이름이고, 모듈이나 값을 넣으면 그 대상이 가진 이름입니다.

```python
print(dir())

import random
print(dir())

import pickle
print(dir())

print(dir(random))
```

`random`을 `import`하기 전과 후의 `dir()` 목록이 다릅니다. `dir(random)`은 `random` 모듈 안의 `randint`, `shuffle` 같은 이름을 보여 줍니다. 리스트와 문자열도 각자 메소드 목록이 있습니다.

```python
lst = [1, 2, 3]
print(dir(lst))

name = "Jim"
print(dir(name))
```

리스트에는 `append`, `sort`가 있고, 문자열에는 `lower`, `replace`가 있습니다. 이름을 찾기 전에 외우지 않아도 되고, `dir`로 목록을 본 뒤 더 긴 설명이 필요하면 `help`를 호출합니다.

```python
print(help(random.randint))
```

`help`는 그 함수가 어떤 인자를 받는지 설명을 출력합니다. 출력이 길면 터미널에서 `q`로 설명을 닫고 다음 코드로 돌아갑니다.

## 🦮 25. 외장 함수

표준 라이브러리지만 `import`해야 쓰는 모듈입니다. 강의에서 다루는 것은 `glob`, `os`, `time`, `datetime`입니다.

`glob`은 패턴에 맞는 파일 이름을 찾습니다. `*.py`는 현재 폴더의 파이썬 파일 목록입니다.

```python
import glob

print(glob.glob("*.py"))
```

`os`는 폴더와 경로를 다룹니다. `getcwd`는 현재 작업 폴더, `listdir`는 그 안의 이름 목록입니다. `path.exists`로 폴더가 있는지 확인한 뒤, 있으면 지우고 없으면 만듭니다. `makedirs`는 폴더를 만들고, `rmdir`는 비어 있는 폴더를 지웁니다.

```python
import os

print(os.getcwd())

folder = "sample_dir"
if os.path.exists(folder):
    print("이미 존재하는 폴더입니다.")
    os.rmdir(folder)
    print(folder, "폴더를 삭제하였습니다.")
else:
    os.makedirs(folder)
    print(folder, "폴더를 생성하였습니다.")

print(os.listdir())
```

같은 코드를 두 번 실행하면 처음에는 폴더가 생기고, 다음엔 이미 있어서 삭제됩니다.

`time`은 현재 시각을 원하는 형식의 문자열로 바꿉니다. `datetime`은 날짜 계산에 씁니다. `timedelta(days=100)`은 100일짜리 간격이고, 오늘 날짜에 더하면 100일 뒤가 됩니다.

```python
import time

print(time.localtime())
print(time.strftime("%Y-%m-%d %H:%M:%S"))

import datetime

print("오늘 날짜는 ", datetime.date.today())

today = datetime.date.today()
td = datetime.timedelta(days=100)
print("우리가 만난지 100일은", today + td)
```

`%Y`는 네 자리 연도, `%m`은 월, `%d`는 일, `%H`는 시, `%M`은 분, `%S`는 초입니다. `localtime()`은 항목이 나뉜 시간 정보이고, `strftime`은 그걸 한 줄 문자열로 만듭니다.

## 🦮 26. 퀴즈 10. 모듈 직접 만들어 부르기

자기소개 문구를 출력하는 함수를 `byme.py`에 만들고, 다른 파일에서 불러와 호출합니다. 모듈을 나누고 `import`하는 감각을 확인하는 마지막 연습입니다.

`byme.py`

```python
def sign():
    print("이 프로그램은 나도코딩에 의해 만들어졌습니다.")
    print("유튜브 : http://youtube.com")
    print("이메일 : nadocoding@gmail.com")
```

같은 폴더의 `practice.py`

```python
import byme

byme.sign()
```

`practice.py`를 실행하면 `byme.py`의 `sign`이 세 줄을 출력합니다. 소개 문구는 모듈 안에만 있으므로, 다른 프로그램에서도 `import byme` 한 줄로 같은 서명을 붙일 수 있습니다. 파일을 직접 실행할 때만 테스트 출력을 보이게 하려면 `byme.py` 맨 아래에 `if __name__ == "__main__":`을 두고 그 안에서 `sign()`을 호출하면 됩니다.
