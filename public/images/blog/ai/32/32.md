## 🦮 앤트로픽 직무별 플러그인 15가지, 1분 설치 가이드

클로드를 만든 앤트로픽이 **자기 회사가 일하는 방식을 담은 직무별 플러그인**을 공개했습니다. 마케팅, 영업, 재무, 법무처럼 직무마다 하나씩 있고, 플러그인 하나에 **일하는 요령, 자주 쓰는 요청, 평소 쓰는 도구 연결**이 한꺼번에 들어 있습니다.

이번 글에서는 15가지 플러그인이 각각 어떤 일에 좋은지, 그리고 클로드 데스크톱 앱에서 1분 만에 설치하는 방법을 정리했습니다.

먼저 결론부터 말씀드리겠습니다.

1. 플러그인은 **직무별로 15개**입니다. 내 직무에 맞는 것 하나만 골라 깔아도 바로 효과가 있습니다.

2. 플러그인을 깔면 **슬랙, 노션, 지메일 같은 업무 도구와 연결**되어, 자료를 복사해 붙여 넣지 않아도 클로드가 직접 읽고 결과를 넣어 줍니다.

3. 설치는 **사용자 지정 → 플러그인 → 추가** 세 번이면 끝납니다.

4. 플러그인 자료 자체는 무료로 공개돼 있지만, 데스크톱 앱의 코워크와 플러그인 기능은 **Pro 이상 유료 요금제**에서 쓸 수 있습니다.

---

## 🦮 1. 준비물

| 항목 | 내용 |
|---|---|
| 클로드 데스크톱 앱 | 최신 버전으로 업데이트해 둡니다 |
| 요금제 | Pro 이상 유료 요금제 |
| 연결할 업무 도구 계정 | 슬랙, 노션 등 실제로 쓰는 도구만 있으면 됩니다 |

---

## 🦮 2. 직무별 플러그인 15가지

앱 화면에서는 영어 이름으로 보입니다. 2026년 11월 공식 저장소 기준입니다.

| 플러그인 (화면 이름) | 이런 일에 좋습니다 |
|---|---|
| 마케팅 (Marketing) | 콘텐츠 초안, 캠페인 기획, 브랜드 말투 점검, 성과 정리 |
| 영업 (Sales) | 고객사 조사, 미팅 준비, 영업 메일 초안 |
| 재무 (Finance) | 분개와 계정 대사, 재무제표 초안, 결산 자료 |
| 법무 (Legal) | 계약서 검토 초안, 비밀유지계약 분류, 위험 조항 정리 |
| 인사 (Human Resources) | 채용, 온보딩, 평가와 사내 정책 자료 |
| 디자인 (Design) | 디자인 피드백, UX 문구, 접근성 점검 |
| 데이터 (Data) | 데이터 조회, 차트 작성, 분석 결과 검증 |
| 개발 (Engineering) | 진행 상황 공유, 코드 리뷰, 장애 대응 정리 |
| 고객 지원 (Customer Support) | 문의 분류, 답변 초안, 해결 사례 문서화 |
| 제품 기획 (Product Management) | 기능 기획서, 로드맵, 사용자 의견 정리 |
| 운영 (Operations) | 거래처 관리, 업무 절차 문서, 변경 관리 |
| 바이오 연구 (Bio Research) | 논문과 유전체 데이터베이스 조사 |
| 소상공인 (Small Business) | 작은 가게의 마케팅·영업·운영 자료 |
| 업무 관리 (Productivity) | 할 일과 일정 정리, 매번 설명하던 업무 맥락 기억 |
| 사내 검색 (Enterprise Search) | 메일·채팅·문서를 한 번에 검색 |

이 15개 외에도 슬랙, 줌, 캔바 같은 **다른 회사가 만든 파트너 플러그인이 같은 목록에 100개 넘게** 올라와 있습니다.

---

## 🦮 3. 평소 쓰는 업무 도구와 바로 이어집니다

플러그인의 가장 큰 장점은 **도구 연결**입니다. 지금까지는 슬랙 대화나 노션 문서를 복사해서 클로드에 붙여 넣어야 했다면, 플러그인을 깔고 나면 클로드가 연결된 도구에서 직접 찾아 읽고 결과도 그쪽에 넣어 줍니다.

| 플러그인 | 연결되는 도구 예시 |
|---|---|
| 마케팅 | 슬랙, 캔바, 피그마, 노션, 허브스팟, 지메일, 구글 캘린더 |
| 영업 | 슬랙, 허브스팟, 세일즈포스, 노션, 지메일, 줌, 구글 드라이브 |
| 디자인 | 슬랙, 피그마, 리니어, 아사나, 노션, 지메일 |

연결할 때는 각 서비스에 **내 계정으로 직접 로그인**합니다. 쓰지 않는 도구는 연결하지 않아도 됩니다.

예를 들어 마케팅 플러그인에 "다음 주 인스타그램 콘텐츠 계획 짜 줘" 한 줄만 보내도, 요일별 주제와 표지 방향까지 정리된 계획이 나옵니다.

---

## 🦮 4. 1분 설치 방법

### 🦄 1단계: 플러그인 메뉴 열기

클로드 데스크톱 앱 왼쪽에서 **사용자 지정 → 플러그인**을 누릅니다. 목록에서 내 직무에 맞는 플러그인을 찾아 선택합니다.

### 🦄 2단계: 추가 누르기

플러그인 상세 화면 오른쪽 위의 **추가** 버튼을 누릅니다. 업무 도구 로그인을 물어보면 쓸 계정으로 연결합니다.

### 🦄 3단계: 켜졌는지 확인

추가 버튼이 있던 자리에 **스위치가 켜져 있으면** 설치가 끝난 것입니다.

## 🦮 5. 바로 복사해서 써 보기

설치한 뒤 코워크에서 새 대화를 열고 아래 문장을 붙여 넣습니다. `[ ]` 부분만 내 일로 바꾸면 됩니다.

```text
[마케팅] 플러그인으로 내 업무를 도와줘.
나는 [인스타그램 계정을 운영하는 1인 마케터]야.
이번 주에 해야 할 일을 정리하고, 가장 먼저 할 일 1개는 결과물까지 바로 만들어 줘.
필요한 자료가 연결된 도구에 있으면 직접 찾아서 써 줘.
```

다른 직무라면 이렇게 바꿔 쓸 수 있습니다.

| 직무 | `[ ]`에 넣을 내용 예시 |
|---|---|
| 재무 | `[재무]` 플러그인 / `[월말 결산을 맡은 재무 담당자]` |
| 인사 | `[인사]` 플러그인 / `[신입 온보딩을 준비하는 인사 담당자]` |
| 고객 지원 | `[고객 지원]` 플러그인 / `[하루 문의 50건을 처리하는 상담원]` |
| 개발 | `[개발]` 플러그인 / `[주간 진행 공유를 써야 하는 프론트엔드 개발자]` |

"가장 먼저 할 일 1개는 결과물까지"라는 문장이 중요합니다. 할 일 목록만 받고 끝나지 않고, 실제로 바로 쓸 수 있는 초안까지 한 번에 받을 수 있습니다.

## 🦮 6. 막혔을 때

| 증상 | 해결 방법 |
|---|---|
| 플러그인 메뉴가 안 보입니다 | 데스크톱 앱을 최신 버전으로 업데이트합니다 |
| 회사 계정에서 추가가 막힙니다 | 조직 관리자에게 플러그인 설치 허용을 요청합니다 |
| 도구 연결이 계속 실패합니다 | 해당 서비스에 로그인된 계정이 맞는지 확인하고, 연결을 끊었다가 다시 연결합니다 |

## 🦮 마치며

직무별 플러그인은 "클로드에게 내 일을 매번 처음부터 설명해야 하는 수고"를 줄여 주는 도구입니다. 앤트로픽이 직무마다 정리해 둔 요령과 요청 방식이 이미 들어 있어서, 내 직무 하나만 골라 깔아도 바로 체감할 수 있습니다.

처음에는 15개를 다 깔기보다 **가장 많이 하는 일과 맞는 플러그인 하나**만 설치하고, 자주 쓰는 도구 한두 개만 연결해서 써 보시길 추천드립니다.
