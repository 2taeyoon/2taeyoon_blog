## 🦮 1. 리스트

리스트는 대괄호 안에 값을 순서대로 넣는 목록입니다. 위치는 문자열과 같이 0부터 셉니다. 숫자만 넣어도 되고, 문자열만 넣어도 됩니다.

```python
subway = [10, 20, 30]
print(subway)

subway = ["유재석", "조세호", "박명수"]
print(subway)
print(subway.index("조세호"))
```

`index`는 그 값이 몇 번 칸에 있는지 알려 줍니다. 조세호는 1번 칸입니다. 없는 값을 찾으면 오류가 납니다.

맨 뒤에 추가할 때는 `append`, 원하는 칸에 끼워 넣을 때는 `insert`입니다. `insert`의 첫 인자는 칸 번호입니다.

```python
subway.append("하하")
print(subway)

subway.insert(1, "정형돈")
print(subway)
```

하하를 넣은 뒤 1번 칸에 정형돈을 끼우면, 원래 1번이었던 조세호부터는 한 칸씩 뒤로 밀립니다.

`pop`은 맨 뒤에서 하나를 꺼내면서 목록에서 뺍니다. 꺼낸 값이 `print`에 출력되고, 목록은 한 칸 짧아집니다.

```python
print(subway.pop())
print(subway)
```

같은 값이 여러 번 있을 수 있습니다. `count`는 그 값이 몇 개인지 셉니다.

```python
subway.append("유재석")
print(subway)
print(subway.count("유재석"))
```

숫자 목록은 `sort`로 오름차순 정렬하고, `reverse`로 현재 순서를 뒤집습니다. `reverse`는 내림차순 정렬이 아니라, 지금 놓인 순서를 반대로 바꾸는 동작입니다. `clear`는 목록을 비웁니다.

```python
num_list = [5, 2, 4, 3, 1]
num_list.sort()
print(num_list)

num_list.reverse()
print(num_list)

num_list.clear()
print(num_list)
```

리스트 한 칸에는 문자열, 숫자, 불리언을 섞어 넣을 수 있습니다. 다른 리스트를 이어 붙일 때는 `extend`를 씁니다. `append`에 리스트를 넣으면 목록 하나가 통째로 한 칸에 들어갑니다.

```python
num_list = [5, 2, 4, 3, 1]
mix_list = ["조세호", 20, True]
print(mix_list)

num_list.extend(mix_list)
print(num_list)
```

## 🦮 2. 사전

리스트는 순번으로 찾습니다. 사전은 <strong>키</strong>로 값을 찾습니다. 중괄호에 `키:값`을 적습니다. 사물함 번호가 키, 그 칸을 쓰는 사람이 값인 상황입니다.

```python
cabinet = {3: "유재석", 100: "김태호"}
print(cabinet[3])
print(cabinet[100])
print(cabinet.get(3))
```

대괄호와 `get`은 둘 다 값을 꺼냅니다. 차이는 키가 없을 때입니다. `cabinet[5]`는 오류가 나서 멈춥니다. `cabinet.get(5)`는 `None`을 주고 계속 갑니다. `get`의 두 번째 인자는 없을 때 대신 보여줄 값입니다.

```python
print(cabinet.get(5))
print(cabinet.get(5, "사용 가능"))
print(3 in cabinet)
print(5 in cabinet)
```

`in`은 그 키가 사전에 있는지 `True` 또는 `False`로 알려 줍니다.

키는 숫자만 되는 것이 아닙니다. 문자열 키도 같은 방식입니다.

```python
cabinet = {"A-3": "유재석", "B-100": "김태호"}
print(cabinet["A-3"])
print(cabinet["B-100"])

cabinet["A-3"] = "김종국"
cabinet["C-20"] = "조세호"
print(cabinet)

del cabinet["A-3"]
print(cabinet)
```

이미 있는 키에 다시 넣으면 값이 바뀝니다. 없는 키에 넣으면 칸이 추가됩니다. `del`은 그 키와 값을 지웁니다.

키만, 값만, 쌍으로 꺼낼 수 있습니다. `clear`는 사전을 비웁니다.

```python
print(cabinet.keys())
print(cabinet.values())
print(cabinet.items())

cabinet.clear()
print(cabinet)
```

`items`는 `(키, 값)` 쌍의 목록입니다. 나중에 `for`로 키와 값을 같이 돌 때 이 쌍을 씁니다.

## 🦮 3. 튜플

튜플은 소괄호로 만듭니다. 한 번 만들면 값을 추가하거나 지우거나 바꾸지 못합니다. 순서가 고정된 메뉴, 좌표처럼 바뀌면 안 되는 짝에 어울립니다.

```python
menu = ("돈까스", "치즈까스")
print(menu[0])
print(menu[1])
```

`menu.add("생선까스")` 같은 추가는 오류입니다. 바꿀 일이 있으면 리스트를 씁니다.

튜플은 여러 변수에 한 번에 값을 넣을 때도 씁니다. 아래 두 코드는 같은 결과입니다.

```python
name = "김종국"
age = 20
hobby = "코딩"
print(name, age, hobby)

(name, age, hobby) = ("김종국", 20, "코딩")
print(name, age, hobby)
```

왼쪽의 이름 개수와 오른쪽의 값 개수가 같아야 합니다.

## 🦮 4. 세트

세트도 중괄호를 쓰지만, 키와 값이 아니라 값만 넣습니다. 같은 값은 하나로 합쳐지고, 순서는 보장되지 않습니다. 그래서 출력 순서가 넣은 순서와 다를 수 있습니다.

```python
my_set = {1, 2, 3, 3, 3}
print(my_set)
```

`3`을 세 번 넣어도 세트 안에는 3이 하나뿐입니다.

두 세트를 비교하는 연산이 있습니다. 문자열 목록으로 세트를 만들 수도 있습니다.

```python
java = {"유재석", "김태호", "양세형"}
python = set(["유재석", "박명수"])

print(java & python)
print(java.intersection(python))

print(java | python)
print(java.union(python))

print(java - python)
print(java.difference(python))
```

1. `&`와 `intersection`은 둘 다 있는 값입니다. 여기선 유재석입니다.
2. `|`와 `union`은 어느 한쪽에라도 있는 값입니다.
3. `-`와 `difference`는 왼쪽에는 있고 오른쪽에는 없는 값입니다.

`add`로 하나 넣고, `remove`로 하나 뺍니다. 없는 값을 `remove`하면 오류가 납니다.

```python
python.add("김태호")
print(python)

java.remove("김태호")
print(java)
```

## 🦮 5. 자료구조 바꾸기

같은 데이터를 리스트, 튜플, 세트로 오갈 수 있습니다. `type`은 지금 어떤 종류인지 알려 줍니다. 중복을 지우고 싶으면 세트로 갔다가, 순서가 필요해지면 다시 리스트로 돌아오면 됩니다.

```python
menu = {"커피", "우유", "주스"}
print(menu, type(menu))

menu = list(menu)
print(menu, type(menu))

menu = tuple(menu)
print(menu, type(menu))

menu = set(menu)
print(menu, type(menu))
```

세트는 순서가 없으므로 리스트로 바꾸는 순간 칸 번호가 실행할 때마다 달라질 수 있습니다.

## 🦮 6. Quiz. 당첨자 뽑기

댓글 이벤트입니다. 1번부터 20번까지 댓글 작성자 중에서 1명은 치킨, 3명은 커피를 받습니다. 추첨은 무작위로 하되, 중복이면 안 됩니다.

`range(1, 21)`은 1부터 20까지입니다. `range` 자체는 `shuffle`을 바로 쓸 수 없어서 `list`로 바꿉니다. `shuffle`은 목록 순서를 섞고, `sample`은 그중 서로 다른 4개를 뽑습니다.

```python
from random import *

users = range(1, 21)
users = list(users)

print(users)
shuffle(users)
print(users)

winners = sample(users, 4)

print(" -- 당첨자 발표 -- ")
print("치킨 당첨자 : {0}".format(winners[0]))
print("커피 당첨자 : {0}".format(winners[1:]))
print(" -- 축하합니다 -- ")
```

`winners[0]`은 치킨 한 명입니다. `winners[1:]`는 그 다음부터 끝까지라 커피 세 명입니다. `sample`이 중복 없이 뽑으므로 치킨 당첨자가 커피에 다시 나오지 않습니다.

## 🦮 7. if

`if`는 조건이 참일 때만 그 아래를 실행합니다. 들여쓰기가 곧 소속입니다. 스페이스 4칸이 기본입니다. 같은 단계의 코드는 들여쓰기가 같아야 합니다.

`elif`는 앞 조건이 아닐 때 다음 조건을 검사합니다. `else`는 위에 적은 조건이 모두 아닐 때입니다.

```python
weather = input("오늘 날씨는 어때요? ")
if weather == "비" or weather == "눈":
    print("우산을 챙기세요")
elif weather == "미세먼지":
    print("마스크를 챙기세요")
else:
    print("준비물 필요 없어요.")
```

`input`으로 받은 값은 문자열입니다. 사용자가 `비` 또는 `눈`이라고 치면 우산 문장이 나옵니다. 둘 중 하나면 되므로 `or`로 이어 붙입니다.

기온은 숫자로 비교해야 합니다. `input`은 항상 문자열을 주므로 `int()`로 바꿉니다. 글자를 입력하면 여기서 오류가 납니다. 그 처리는 3편의 예외 처리에서 다룹니다.

```python
temp = int(input("기온은 어때요? "))
if 30 <= temp:
    print("너무 더워요. 나가지 마세요")
elif 10 <= temp and temp < 30:
    print("괜찮은 날씨예요")
elif 0 <= temp and temp < 10:
    print("외투를 챙기세요")
else:
    print("너무 추워요. 나가지 마세요")
```

`10 <= temp and temp < 30`은 `10 <= temp < 30`으로 줄여 쓸 수 있습니다. `0 <= temp < 10`도 같습니다. 30 이상, 10 이상 30 미만, 0 이상 10 미만, 그 아래라는 순서로 갈라집니다. 위에서 이미 걸린 조건은 아래 `elif`까지 내려가지 않습니다.

## 🦮 8. for

`for`는 목록이나 범위를 하나씩 꺼내 같은 일을 반복합니다. 꺼낸 값이 매번 `waiting_no`에 들어갑니다.

```python
for waiting_no in [0, 1, 2, 3, 4]:
    print("대기번호 : {0}".format(waiting_no))
```

목록을 직접 적지 않고 `range`로 만들 수 있습니다. `range(5)`는 0부터 5 미만, 즉 0, 1, 2, 3, 4입니다. `range(1, 6)`은 1부터 6 미만입니다. 끝 숫자는 포함되지 않습니다.

```python
for waiting_no in range(1, 6):
    print("대기번호 : {0}".format(waiting_no))
```

문자열 목록도 같은 모양입니다.

```python
starbucks = ["아이언맨", "토르", "아이엠 그루트"]
for customer in starbucks:
    print("{0}, 커피가 준비되었습니다.".format(customer))
```

반복이 끝나면 `customer`는 마지막으로 꺼낸 값을 가진 채 남습니다. 반복 횟수는 목록 길이와 같습니다.

## 🦮 9. while

`while`은 조건이 참인 동안 계속합니다. 조건을 바꾸는 줄이 없으면 끝나지 않습니다.

손님을 5번만 부릅니다. `index`가 1 이상인 동안 출력하고 1씩 줄입니다. 0이 되면 반복을 빠져나간 뒤 폐기 문장을 출력합니다.

```python
customer = "토르"
index = 5
while index >= 1:
    print("{0}, 커피가 준비 되었습니다. {1} 번 남았어요.".format(customer, index))
    index -= 1
    if index == 0:
        print("커피는 폐기처분되었습니다.")
```

`while True`는 조건이 항상 참이라 스스로 멈추지 않습니다. 강의에서는 무한 호출을 보여 준 뒤, 편집기에서 실행을 중단하는 방법으로 설명합니다. 아래에 다른 코드가 있으면 이 반복에 막혀 도달하지 못합니다.

```python
customer = "아이언맨"
index = 1
while True:
    print("{0}, 커피가 준비 되었습니다. 호출 {1} 회".format(customer, index))
    index += 1
```

손님이 직접 이름을 입력하게 하면, 원하는 이름이 나올 때까지 묻습니다. `person`이 `customer`와 같아지는 순간 조건이 거짓이 되어 반복이 끝납니다.

```python
customer = "토르"
person = "Unknown"

while person != customer:
    print("{0}, 커피가 준비 되었습니다.".format(customer))
    person = input("이름이 어떻게 되세요? ")
```

처음 `person`은 `"Unknown"`이라 조건이 참입니다. 루프 안에서 이름을 새로 받아야 비교가 갱신됩니다. 입력값을 받는 줄이 없으면 영원히 `"Unknown"`인 채로 돕니다.

## 🦮 10. continue와 break

`continue`는 이번 차례의 남은 코드를 건너뛰고 다음 차례로 갑니다. `break`는 반복 전체를 끝냅니다.

1번부터 10번까지 책을 읽힙니다. 2번과 5번은 결석이라 호명하지 않고 넘어갑니다. 7번은 책을 가져오지 않았으므로 그 자리에서 수업을 멈춥니다.

```python
absent = [2, 5]
no_book = [7]
for student in range(1, 11):
    if student in absent:
        continue
    elif student in no_book:
        print("오늘 수업 여기까지. {0}는 교무실로 따라와".format(student))
        break
    print("{0}, 책을 읽어봐".format(student))
```

`student`가 2일 때 `continue`를 만나면 아래 `print`는 실행되지 않고 3번으로 갑니다. 7번에서 `break`를 만나면 8, 9, 10번은 호명되지 않습니다. `continue`와 `break` 모두 들여쓰기된 반복 안에서만 의미가 있습니다.

## 🦮 11. 한 줄 for

리스트의 모든 값에 같은 계산을 해서 새 리스트를 만드는 문법입니다. 대괄호 안에 `표현식 for 변수 in 목록`을 적습니다.

출석 번호 1, 2, 3, 4, 5 앞에 100을 붙인다고 하면, 각 번호에 100을 더합니다.

```python
students = [1, 2, 3, 4, 5]
print(students)
students = [i + 100 for i in students]
print(students)
```

결과는 `[101, 102, 103, 104, 105]`입니다.

학생 이름을 길이로 바꿀 수도 있고, 대문자로 바꿀 수도 있습니다.

```python
students = ["Iron man", "Thor", "I am groot"]
students = [len(i) for i in students]
print(students)

students = ["Iron man", "Thor", "I am groot"]
students = [i.upper() for i in students]
print(students)
```

첫 결과는 각 이름의 글자 수입니다. 공백도 길이에 포함됩니다. 둘째는 `IRON MAN`, `THOR`, `I AM GROOT`입니다. `len(i)`를 먼저 실행해 `students`를 숫자 목록으로 바꾼 뒤에는 `upper`를 쓸 수 없으므로, 대문자 예제는 이름 목록을 다시 넣습니다.

## 🦮 12. Quiz. 택시 승객

50명의 승객과 매칭합니다. 운행 소요 시간은 5분에서 50분 사이의 난수입니다. 5분 이상 15분 이하인 손님만 태웁니다. 태운 승객 수를 마지막에 출력합니다.

```python
from random import *

cnt = 0
for i in range(1, 51):
    time = randrange(5, 51)
    if 5 <= time <= 15:
        print("[O] {0}번째 손님 (소요시간 : {1}분)".format(i, time))
        cnt += 1
    else:
        print("[ ] {0}번째 손님 (소요시간 : {1}분)".format(i, time))

print("총 탑승 승객 : {0} 분".format(cnt))
```

`range(1, 51)`은 1번부터 50번 손님입니다. `randrange(5, 51)`은 5 이상 51 미만이라 50분까지 나옵니다. 끝값을 포함하고 싶으면 `randint(5, 50)`을 써도 같은 범위입니다.

조건에 맞으면 `[O]`와 함께 `cnt`를 1 올립니다. 아니면 `[ ]`만 출력합니다. 영상 코드의 마지막 단위는 `분`으로 적혀 있습니다. 세고 있는 것은 승객 수이므로 문장만 본다면 `명`이 맞습니다.

## 🦮 13. 함수

같은 `print`를 여러 번 적지 않으려면 함수로 묶습니다. `def`로 정의하고, 이름 뒤에 괄호를 붙여 호출합니다. 정의만 해서는 실행되지 않습니다. 호출한 줄에서 본문이 실행됩니다.

```python
def open_account():
    print("새로운 계좌가 생성되었습니다.")

open_account()
```

함수는 호출보다 위에 정의되어 있어야 합니다. 파이썬은 파일을 위에서 아래로 읽기 때문입니다.

## 🦮 14. 전달값과 반환값

괄호 안은 밖에서 넘겨주는 값입니다. `return`은 함수가 끝난 뒤 가지고 나올 값입니다. 출력만 하고 `return`이 없으면, 함수 밖의 변수는 바뀌지 않습니다.

입금은 잔액에 돈을 더해 그 결과를 돌려줍니다.

```python
def deposit(balance, money):
    print("입금이 완료되었습니다. 잔액은 {0} 원입니다.".format(balance + money))
    return balance + money
```

출금은 잔액이 충분할 때만 뺍니다. 부족하면 잔액을 그대로 돌려줍니다.

```python
def withdraw(balance, money):
    if balance >= money:
        print("출금이 완료되었습니다. 잔액은 {0} 원입니다.".format(balance - money))
        return balance - money
    else:
        print("출금이 완료되지 않았습니다. 잔액은 {0} 원입니다.".format(balance))
        return balance
```

야간 출금은 수수료 100원을 뗍니다. `return`에 값을 쉼표로 나열하면 두 값을 함께 돌려주고, 받는 쪽도 변수 두 개로 받습니다.

```python
def withdraw_night(balance, money):
    commission = 100
    return commission, balance - money - commission

balance = 0
balance = deposit(balance, 1000)
balance = withdraw(balance, 2000)
balance = withdraw(balance, 500)
commission, balance = withdraw_night(balance, 500)
print("수수료 {0} 원이며, 잔액은 {1} 원입니다.".format(commission, balance))
```

입금 후 잔액은 1000원입니다. 2000원 출금은 실패해서 잔액이 그대로입니다. 500원 출금은 성공해서 500원이 됩니다. 야간 출금은 수수료 100원을 더 빼 잔액 0원, 수수료 100원입니다. `balance = deposit(...)`처럼 돌아온 값을 다시 넣어야 다음 함수가 갱신된 잔액을 받습니다.

## 🦮 15. 기본값

같은 나이, 같은 언어를 매번 적기 번거로우면 기본값을 둡니다. 호출할 때 그 인자를 생략하면 기본값이 들어갑니다. 기본값이 있는 인자는 뒤쪽에 둡니다.

```python
def profile(name, age, main_lang):
    print("이름 : {0}\t나이 : {1}\t주 사용 언어 : {2}".format(name, age, main_lang))

profile("유재석", 20, "파이썬")
profile("김태호", 25, "자바")
```

두 사람 다 나이가 17이고 언어가 파이썬이라면, 이름만 넘겨도 됩니다.

```python
def profile(name, age=17, main_lang="파이썬"):
    print("이름 : {0}\t나이 : {1}\t주 사용 언어 : {2}".format(name, age, main_lang))

profile("유재석")
profile("김태호")
```

`\t`는 탭입니다. 이름과 나이 사이를 칸에 맞춰 띄웁니다.

def profile(name, age, main_lang):

## 🦮 17. 가변 인자

언어 개수가 사람마다 다르면 매개변수를 `lang1`, `lang2`처럼 고정할 수 없습니다. 쓰는 사람이 없거나, 여섯 개를 넘는 사람이 생기면 함수를 고쳐야 합니다.

`*language`는 개수를 한정하지 않고 받습니다. 함수 안에서는 튜플로 들어옵니다. `for`로 하나씩 출력하면 됩니다. `print`의 `end=" "`는 줄바꿈 대신 공백을 넣어, 언어가 한 줄에 이어지게 합니다. 마지막에 `print()`를 한 번 더 호출해야 다음 사람이 새 줄에서 시작합니다.

```python
def profile(name, age, *language):
    print("이름 : {0}\t나이 : {1}\t".format(name, age), end=" ")
    for lang in language:
        print(lang, end=" ")
    print()

profile("유재석", 20, "Python", "Java", "C", "C++", "C#", "JavaScript")
profile("김태호", 25, "Kotlin", "Swift")
```

유재석은 언어가 여섯 개, 김태호는 두 개입니다. 같은 함수가 둘 다 받습니다. 언어를 하나도 넘기지 않으면 `for`는 그냥 한 번도 돌지 않습니다.

## 🦮 18. 지역변수와 전역변수

함수 밖에서 만든 `gun`은 전역변수입니다. 함수 안에서 같은 이름으로 값을 읽거나 바꾸려면, 파이썬은 그걸 함수 안의 지역변수로 보려다 아직 값이 없다고 오류를 냅니다.

```python
gun = 10

def checkpoint(soldiers):
    global gun
    gun = gun - soldiers
    print("[함수 내] 남은 총 : {0}".format(gun))

print("전체 총 : {0}".format(gun))
checkpoint(2)
print("남은 총 : {0}".format(gun))
```

`global gun`이라고 적으면 함수 안에서도 밖의 `gun`을 고칩니다. 전체 10정에서 2정을 써 남은 총은 8정입니다. 함수가 끝난 뒤의 `print`도 8을 출력합니다. `global` 없이 `gun = gun - soldiers`를 적으면 `UnboundLocalError`가 납니다.

전역변수를 직접 고치면 함수가 밖의 상태에 기대게 되어 읽기 어렵습니다. 총을 인자로 받고, 남은 총을 `return`하는 편이 분명합니다.

```python
gun = 10

def checkpoint_ret(gun, soldiers):
    gun = gun - soldiers
    print("[함수 내] 남은 총 : {0}".format(gun))
    return gun

print("전체 총 : {0}".format(gun))
gun = checkpoint_ret(gun, 2)
print("남은 총 : {0}".format(gun))
```

여기의 `gun = gun - soldiers`는 함수 인자 `gun`을 바꾸는 것입니다. 밖의 전역 `gun`과는 다른 변수입니다. 그래서 돌아온 값을 `gun = checkpoint_ret(...)`로 다시 넣어야 밖의 총 개수가 바뀝니다.

## 🦮 19. Quiz. 표준 체중

표준 체중은 키(m)의 제곱에 남자는 22, 여자는 21을 곱합니다. 키는 센티미터로 받고, 함수에 넘기기 전에 100으로 나눠 미터로 바꿉니다. 결과는 소수점 둘째 자리까지 반올림합니다.

```python
def std_weight(height, gender):
    if gender == "남자":
        return height * height * 22
    else:
        return height * height * 21

height = 175
gender = "남자"
weight = round(std_weight(height / 100, gender), 2)
print("키 {0}cm {1}의 표준 체중은 {2}kg 입니다.".format(height, gender, weight))
```

175cm 남자는 `1.75 * 1.75 * 22`입니다. `round`의 두 번째 인자 2는 소수점 둘째 자리까지 남기라는 뜻입니다. 성별을 `"여자"`로 바꾸면 곱하는 수가 21로 바뀝니다.

## 🦮 20. 표준 입출력

`print`는 값을 쉼표로 여러 개 받을 수 있습니다. `sep`는 그 값 사이에 넣을 문자, `end`는 마지막에 넣을 문자입니다. 기본 `sep`는 공백 하나, 기본 `end`는 줄바꿈입니다.

```python
print("Python", "Java", "JavaScript", sep=" vs ")
print("Python", "Java", sep=",", end="?")
print("무엇이 더 재밌을까요?")
```

첫 줄은 `Python vs Java vs JavaScript`입니다. 둘째 줄은 끝에 물음표를 붙이고 줄을 바꾸지 않으므로, 다음 `print`가 그 뒤에 이어집니다.

표준 출력과 표준 에러는 둘 다 화면에 보이지만 용도가 다릅니다. 정상적인 결과는 `stdout`, 오류 메시지는 `stderr`로 보냅니다. 로그를 파일로 나눌 때 이 구분이 쓰입니다.

```python
import sys

print("Python", "Java", file=sys.stdout)
print("Python", "Java", file=sys.stderr)
```

시험 점수는 과목 이름은 왼쪽, 점수는 오른쪽에 맞춥니다. `ljust(8)`은 너비 8칸에서 왼쪽 정렬, `rjust(4)`는 너비 4칸에서 오른쪽 정렬입니다. 글자 수가 너비보다 짧으면 나머지는 공백입니다.

```python
scores = {"수학": 0, "영어": 50, "코딩": 100}
for subject, score in scores.items():
    print(subject.ljust(8), str(score).rjust(4), sep=":")
```

`items()`가 키와 값을 함께 주므로 `for`에서 변수 두 개로 받습니다. 점수는 숫자라 `rjust`를 쓰려면 `str()`로 바꿉니다.

대기번호는 세 칸으로 맞추고 빈칸을 0으로 채웁니다. `zfill(3)`은 문자열 앞에서 0을 채워 길이를 3으로 만듭니다.

```python
for num in range(1, 21):
    print("대기번호 : " + str(num).zfill(3))
```

1은 `001`, 20은 `020`입니다.

`input`으로 받은 값은 숫자를 쳐도 문자열입니다. `type`으로 확인하면 `<class 'str'>`가 나옵니다. 숫자로 계산하려면 `int()`가 필요합니다.

```python
answer = input("아무 값이나 입력하세요 : ")
print(type(answer))
print("입력하신 값은 " + answer + "입니다.")
```

## 🦮 21. 다양한 출력 포맷

`format`의 중괄호 안에 콜론을 붙이면 빈칸, 부호, 쉼표, 소수 자릿수를 지정할 수 있습니다.

```python
print("{0: >10}".format(500))
print("{0: >+10}".format(500))
print("{0: >+10}".format(-500))
print("{0:_<10}".format(500))
print("{0:,}".format(100000000000))
print("{0:+,}".format(100000000000))
print("{0:+,}".format(-100000000000))
print("{0:^<+30,}".format(100000000000))
print("{0:f}".format(5 / 3))
print("{0:.2f}".format(5 / 3))
```

1. `{0: >10}`은 열 칸 안에서 오른쪽 정렬입니다. `>` 앞의 공백이 빈칸을 채우는 문자입니다. 500 앞에 공백이 붙습니다.
2. `+`를 넣으면 양수에도 부호가 붙습니다. 음수는 원래부터 `-`가 붙습니다.
3. `{0:_<10}`은 왼쪽 정렬이고, 남는 칸을 `_`로 채웁니다.
4. `,`는 천 단위 쉼표입니다. `+`와 함께 쓰면 부호와 쉼표가 같이 나옵니다.
5. `^<+30,`처럼 이어 쓰면, 부호가 있는 금액을 30칸 안에 넣고 왼쪽 정렬한 뒤 남는 칸을 `^`로 채웁니다. 기호를 조합하는 순서라, 하나씩 출력해 보며 익히는 편이 빠릅니다.
6. `:f`는 실수를 출력합니다. 기본은 소수점 아래가 길게 나옵니다. `.2f`는 둘째 자리까지입니다. `5 / 3`은 `1.67`로 반올림됩니다.

## 🦮 22. 파일 입출력

`open`의 두 번째 인자가 모드입니다. `w`는 새로 쓰기라, 같은 이름의 파일이 있으면 내용을 지우고 다시 씁니다. `a`는 파일 맨 뒤에 이어 씁니다. `r`은 읽기입니다. 한글이 깨지면 `encoding="utf8"`을 붙입니다. 연 파일은 `close`로 닫습니다.

```python
score_file = open("score.txt", "w", encoding="utf8")
print("수학 : 0", file=score_file)
print("영어 : 50", file=score_file)
score_file.close()
```

`print`의 `file`에 파일 객체를 넘기면 화면 대신 그 파일에 출력됩니다. `print`는 끝에 줄바꿈을 넣으므로 과목마다 한 줄씩 저장됩니다.

이어 쓰기는 `write`를 쓸 수 있습니다. `write`는 줄바꿈을 자동으로 넣지 않아서 `\n`을 직접 적습니다.

```python
score_file = open("score.txt", "a", encoding="utf8")
score_file.write("과학 : 80")
score_file.write("\n코딩 : 100")
score_file.close()
```

한 번에 읽으려면 `read`입니다. 파일 전체가 문자열 하나로 돌아옵니다.

```python
score_file = open("score.txt", "r", encoding="utf8")
print(score_file.read())
score_file.close()
```

한 줄씩 읽으려면 `readline`입니다. 호출할 때마다 다음 줄로 넘어가고, 줄 끝의 줄바꿈도 포함해서 가져옵니다. `print`가 또 줄바꿈을 넣으면 빈 줄이 생기므로 `end=""`로 막습니다. 줄 수를 미리 알 때 횟수만큼 호출합니다.

```python
score_file = open("score.txt", "r", encoding="utf8")
print(score_file.readline(), end="")
print(score_file.readline(), end="")
print(score_file.readline(), end="")
print(score_file.readline(), end="")
score_file.close()
```

줄 수를 모르면 `while`로 읽다가, 더 이상 줄이 없으면 빈 문자열이 오므로 그때 `break`합니다.

```python
score_file = open("score.txt", "r", encoding="utf8")
while True:
    line = score_file.readline()
    if not line:
        break
    print(line, end="")
score_file.close()
```

`readlines`는 모든 줄을 리스트로 가져옵니다. 리스트이므로 `for`로 돕니다.

```python
score_file = open("score.txt", "r", encoding="utf8")
lines = score_file.readlines()
for line in lines:
    print(line, end="")
score_file.close()
```

파일을 닫지 않으면 다른 프로그램이 그 파일을 못 열거나, 쓰던 내용이 디스크에 다 내려가지 않을 수 있습니다.

## 🦮 23. pickle

`pickle`은 리스트나 사전 같은 파이썬 값을 파일에 그대로 저장하고, 나중에 같은 모양으로 불러옵니다. 사람이 읽는 글이 아니라 바이너리이므로 모드는 `wb`, `rb`입니다. `encoding`은 붙이지 않습니다.

```python
import pickle

profile_file = open("profile.pickle", "wb")
profile = {"이름": "박명수", "나이": 30, "취미": ["축구", "골프", "코딩"]}
print(profile)
pickle.dump(profile, profile_file)
profile_file.close()
```

`dump`의 첫 인자는 저장할 값, 둘째는 파일입니다. 메모장으로 열면 글자가 깨져 보입니다. `load`로 읽어야 사전으로 돌아옵니다.

```python
profile_file = open("profile.pickle", "rb")
profile = pickle.load(profile_file)
print(profile)
profile_file.close()
```

취미가 리스트인 것까지 그대로 복원됩니다. 저장한 파이썬 버전과 읽는 쪽이 크게 다르면 `load`가 실패할 수 있습니다.

## 🦮 24. with

`open`마다 `close`를 적으면 빠뜨리기 쉽습니다. `with` 블록이 끝나면 파일이 자동으로 닫힙니다.

```python
import pickle

with open("profile.pickle", "rb") as profile_file:
    print(pickle.load(profile_file))
```

`as` 뒤의 이름이 블록 안에서 쓰는 파일 객체입니다. 쓰기도 같습니다.

```python
with open("study.txt", "w", encoding="utf8") as study_file:
    study_file.write("파이썬을 열심히 공부하고 있어요")

with open("study.txt", "r", encoding="utf8") as study_file:
    print(study_file.read())
```

블록 안에서 오류가 나도 `with`는 파일을 닫고 빠져나옵니다.

## 🦮 25. Quiz. 보고서 파일

회사 주간 보고서를 1주차부터 50주차까지 파일로 만듭니다. 파일 이름은 `1주차.txt` 형태이고, 안에는 주차, 부서, 이름, 업무 요약 칸이 있습니다. 내용은 나중에 채울 빈 양식입니다.

```python
for i in range(1, 51):
    with open(str(i) + "주차.txt", "w", encoding="utf8") as report_file:
        report_file.write("- {0} 주차 주간보고 -".format(i))
        report_file.write("\n부서 :")
        report_file.write("\n이름 :")
        report_file.write("\n업무 요약 :")
```

`range(1, 51)`인 이유는 50을 포함하기 위해서입니다. `with` 덕분에 파일 50개를 열어도 하나씩 닫힙니다. 스크립트를 실행한 폴더에 txt 파일 50개가 생깁니다. 이미 같은 이름이 있으면 `w` 모드가 그 내용을 지우고 다시 씁니다.
