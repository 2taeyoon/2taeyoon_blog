## 🦮 1. 파이썬을 실행할 환경

파이썬은 읽고 쓰기 쉬운 프로그래밍 언어입니다. 강의에서는 설치부터 시작합니다. [python.org](https://www.python.org/downloads/)에서 설치 파일을 받습니다. Windows라면 설치 첫 화면의 <strong>Add python.exe to PATH</strong>를 켜 둡니다. 이 항목을 빼먹으면 나중에 터미널에서 `python`과 `pip`를 찾지 못합니다.

편집기는 Visual Studio Code를 쓰고, 마켓플레이스에서 Python 확장을 설치합니다. 영상 속 벌레 아이콘이나 Debug 버튼은 지금 화면과 다를 수 있습니다. 그때는 편집기 우측 상단의 Run으로 `.py` 파일을 실행하면 됩니다. 확장이 pylint 설치를 권하면 터미널에서 한 번 설치합니다.

```bash
pip install pylint
```

첫 파일은 `practice.py`처럼 `.py`로 저장합니다. 파일 이름을 `random.py`로 짓으면, 나중에 공식 `random` 대신 그 파일을 읽어 오류가 납니다.

코드를 실행하면 컴퓨터는 위에서 아래로 한 줄씩 읽습니다. 화면에 글을 찍는 가장 작은 프로그램은 이렇습니다.

```python
print("안녕하세요")
```

`print`는 괄호 안을 화면에 보여주는 함수입니다. 이 한 줄이 출력되면 설치는 끝난 것입니다.

## 🦮 2. 숫자 자료형

숫자에는 소수점이 없는 정수와 소수점이 있는 실수가 있습니다. 따옴표 없이 적으면 숫자로 취급되고, 사칙연산도 그 자리에서 계산됩니다.

```python
print(5)
print(-10)
print(3.14)
print(1000)
print(5 + 3)
print(2 * 8)
print(3 * (3 + 1))
```

`print(5)`는 숫자 5를 그대로 출력합니다. `print(5 + 3)`은 5와 3을 더한 결과 8을 출력합니다. 괄호가 있으면 괄호 안을 먼저 계산하므로 `3 * (3 + 1)`은 12입니다.

## 🦮 3. 문자열 자료형

글자는 따옴표로 감쌉니다. 작은따옴표와 큰따옴표는 같습니다. 따옴표가 없으면 파이썬은 그 단어를 변수 이름으로 오해합니다.

같은 글자를 여러 번 이어 붙일 때는 곱하기를 씁니다. `"ㅋ" * 9`는 ㅋ을 아홉 번 붙인 문자열입니다.

```python
print('풍선')
print("나비")
print("ㅋㅋㅋㅋㅋㅋㅋㅋㅋ")
print("ㅋ" * 9)
```

## 🦮 4. boolean 자료형

불리언은 참과 거짓입니다. `True`와 `False`는 첫 글자가 대문자입니다. `true`라고 쓰면 인식하지 못합니다.

비교식의 결과도 불리언입니다. `not`은 참과 거짓을 뒤집습니다.

```python
print(5 > 10)
print(5 < 10)
print(True)
print(False)
print(not True)
print(not False)
print(not (5 > 10))
```

`5 > 10`은 거짓이라 `False`가 나옵니다. `not (5 > 10)`은 그 거짓을 뒤집으므로 `True`입니다.

## 🦮 5. 변수

변수는 값을 담아 두는 이름입니다. 등호 `=`는 “같다”가 아니라 <strong>오른쪽 값을 왼쪽 이름에 넣는다</strong>는 뜻입니다. 한 번 넣어 두면 이름을 적을 때마다 그 값이 꺼내집니다.

```python
animal = "강아지"
name = "연탄이"
age = 4
hobby = "산책"
is_adult = age >= 3
```

`age`는 숫자 4입니다. `is_adult`에는 비교 결과가 들어갑니다. 4가 3 이상이므로 `True`입니다.

문자열끼리 붙일 때는 `+`를 씁니다. 숫자와 문자열은 그대로 붙이지 못합니다. 나이를 문장에 넣으려면 `str()`로 글자로 바꿉니다.

```python
print("우리집 " + animal + "의 이름은 " + name + "예요")
print(name + "는 " + str(age) + "살이며, " + hobby + "을 아주 좋아해요")
print(name, "는", age, "살이며,", hobby, "을 아주 좋아해요")
print(name + "는 어른일까요? " + str(is_adult))
```

세 번째 `print`는 쉼표로 값을 나열합니다. 타입이 달라도 출력되지만, 항목 사이에 공백이 하나 들어갑니다. `+`로 붙이면 공백은 직접 문자열 안에 적어야 합니다.

`+` 앞에 값이 없으면 문법 오류입니다. `print(+ name)`처럼 시작하면 안 됩니다. 수학에서 `+ 1`만 단독으로 성립하지 않는 것과 같습니다.

변수에 새 값을 넣으면 이전 값은 사라집니다.

```python
animal = "고양이"
name = "해피"
age = 4
hobby = "낮잠"
is_adult = age >= 3
```

같은 `print` 문장을 다시 실행하면 고양이 문장이 나옵니다. 문장은 그대로 두고 변수만 바꾼 것입니다.

## 🦮 6. 주석

주석은 실행되지 않는 메모입니다. 한 줄 주석은 `#`입니다. `#`부터 그 줄 끝까지는 컴퓨터가 무시합니다.

```python
# 변수에 값을 넣고, 문장만 다시 사용한다
animal = "강아지"
```

여러 줄을 한꺼번에 빼 두고 싶을 때는 작은따옴표 세 개, 또는 큰따옴표 세 개로 감쌉니다.

```python
'''
여러 줄은
이렇게 주석이 됩니다
'''
```

영역을 선택한 뒤 `Ctrl + /`를 누르면 선택 영역이 주석이 되고, 한 번 더 누르면 해제됩니다. 동작하지 않으면 `Ctrl + K` 다음 `Ctrl + C`로 주석을 켜고, `Ctrl + K` 다음 `Ctrl + U`로 해제합니다.

## 🦮 8. 연산자

계산 기호와 비교 기호를 구분합니다.

| 기호 | 하는 일 | 예 |
| --- | --- | --- |
| `+` `-` `*` | 더하기, 빼기, 곱하기 | `2 * 8`은 16 |
| `/` | 나누기. 결과는 실수 | `6 / 3`은 2.0 |
| `//` | 몫만 | `5 // 3`은 1 |
| `%` | 나머지 | `5 % 3`은 2 |
| `**` | 거듭제곱 | `2 ** 3`은 8 |

```python
print(1 + 1)
print(3 - 2)
print(5 * 2)
print(6 / 3)

print(2 ** 3)
print(5 % 3)
print(10 % 3)
print(5 // 3)
print(10 // 3)
```

`6 / 3`은 나누어떨어져도 `2.0`처럼 실수로 나옵니다. 몫만 원하면 `//`를 씁니다. `10 // 3`은 3이고, 나머지 `10 % 3`은 1입니다.

비교 결과는 `True` 또는 `False`입니다. `=`는 저장이고, `==`는 같은지 비교입니다.

```python
print(10 > 3)
print(4 >= 7)
print(10 < 3)
print(5 <= 5)

print(3 == 3)
print(4 == 2)
print(3 + 4 == 7)
print(1 != 3)
print(not (1 != 3))
```

`!=`는 다르다는 뜻입니다. `1 != 3`은 참이고, 그 앞에 `not`을 붙이면 거짓이 됩니다.

조건을 이어 붙이는 방법도 두 가지씩 있습니다. `and`와 `&`는 둘 다 참일 때 참입니다. `or`와 `|`는 하나라도 참이면 참입니다.

```python
print((3 > 0) and (3 < 5))
print((3 > 0) & (3 < 5))

print((3 > 0) or (3 > 5))
print((3 > 0) | (3 > 5))

print(5 > 4 > 3)
print(5 > 4 > 7)
```

`5 > 4 > 3`은 5가 4보다 크고, 4가 3보다 큰지 한 줄에 물어본 것입니다. 둘 다 참이라 `True`입니다. `5 > 4 > 7`은 뒤쪽이 거짓이라 `False`입니다.

## 🦮 9. 간단한 수식

곱셈과 나눗셈은 덧셈보다 먼저 계산됩니다. 순서를 바꾸고 싶으면 괄호를 칩니다.

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

첫 줄은 3 곱하기 4를 먼저 해서 14입니다. 둘째 줄은 괄호 때문에 5 곱하기 4, 즉 20입니다.

같은 변수에 계산 결과를 다시 넣을 수 있습니다. `number = number + 2`는 “지금 값에 2를 더해서 다시 넣어라”입니다. 이 문장은 `+=`로 줄일 수 있고, 빼기·곱하기·나누기·나머지도 같은 모양입니다.

```python
number = 2 + 3 * 4
print(number)
number = number + 2
print(number)
number += 2
print(number)
number *= 2
print(number)
number /= 2
print(number)
number -= 2
print(number)
number %= 2
print(number)
```

`/=`를 만나는 순간 값은 실수가 됩니다. 그 뒤의 `-=`, `%=`도 실수끼리의 계산입니다.

## 🦮 10. 숫자 처리 함수

이미 만들어져 있는 함수로 숫자를 다룰 수 있습니다.

```python
print(abs(-5))
print(pow(4, 2))
print(max(5, 12))
print(min(5, 12))
print(round(3.14))
print(round(4.99))
```

`abs`는 절댓값이라 `-5`가 5가 됩니다. `pow(4, 2)`는 4의 2제곱입니다. `max`는 더 큰 값, `min`은 더 작은 값입니다. `round`는 반올림이라 `3.14`는 3, `4.99`는 5가 됩니다.

내림, 올림, 제곱근은 `math`에서 가져옵니다.

```python
from math import *

print(floor(4.99))
print(ceil(3.14))
print(sqrt(16))
```

`floor`는 소수점 아래를 버려 4가 됩니다. `ceil`은 올림이라 4가 됩니다. `sqrt(16)`은 16의 제곱근 4.0입니다. `from math import *`는 math 안의 이름을 앞에 `math.`를 붙이지 않고 쓰겠다는 뜻입니다.

## 🦮 11. 랜덤 함수

무작위 값이 필요하면 `random`을 불러옵니다. 범위를 읽을 때 끝이 포함되는지가 중요합니다.

```python
from random import *

print(random())
print(random() * 10)
print(int(random() * 10))
print(int(random() * 10) + 1)
print(int(random() * 45) + 1)
print(randrange(1, 46))
print(randint(1, 45))
```

1. `random()`은 0 이상 1 미만의 실수입니다.
2. 10을 곱하면 0 이상 10 미만이 됩니다. `int()`로 감싸면 소수점 아래가 잘려 0부터 9까지의 정수가 됩니다.
3. 거기에 1을 더하면 1부터 10까지입니다.
4. 로또처럼 1부터 45까지가 필요하면 `int(random() * 45) + 1`입니다.
5. `randrange(1, 46)`은 1 이상 46 미만입니다. 45까지이고, 46은 나오지 않습니다.
6. `randint(1, 45)`는 1 이상 45 이하입니다. 끝값도 포함됩니다.

실행할 때마다 숫자가 바뀝니다. 같은 코드인데 출력이 다른 것이 정상입니다.

## 🦮 14. 슬라이싱

문자열의 각 글자에는 위치가 있습니다. 첫 글자는 1이 아니라 <strong>0</strong>입니다. 주민등록번호 모양의 문자열로 필요한 칸만 꺼냅니다.

```python
jumin = "990120-1234567"

print("성별 : " + jumin[7])
print("연 : " + jumin[0:2])
print("월 : " + jumin[2:4])
print("일 : " + jumin[4:6])

print("생년월일 : " + jumin[:6])
print("뒤 7자리 : " + jumin[7:])
print("뒤 7자리 (뒤에부터) : " + jumin[-7:])
```

`jumin[7]`은 한 칸입니다. 하이픈이 6번 칸이므로 7번 칸은 성별 숫자 1입니다.

`[시작:끝]`에서 끝 위치는 포함하지 않습니다. `jumin[0:2]`는 0번과 1번, 즉 `99`입니다. `jumin[2:4]`는 월 `01`, `jumin[4:6]`은 일 `20`입니다.

시작을 비우면 처음부터입니다. `jumin[:6]`은 `990120`입니다. 끝을 비우면 끝까지입니다. `jumin[7:]`은 `1234567`입니다.

음수는 뒤에서부터 셉니다. `jumin[-7:]`도 뒤 7자리 `1234567`입니다. `-1`이 맨 끝 글자입니다.

## 🦮 15. 문자열 처리 함수

```python
python = "Python is Amazing"
print(python.lower())
print(python.upper())
print(python[0].isupper())
print(len(python))
print(python.replace("Python", "Java"))
```

`lower`는 모두 소문자, `upper`는 모두 대문자로 바꾼 새 문자열을 만듭니다. 원래 `python` 변수는 바뀌지 않습니다. `python[0]`은 `P`이고, `isupper()`는 그 글자가 대문자인지 확인해 `True`를 줍니다. `len`은 공백을 포함한 길이입니다. `replace`는 찾은 부분을 다른 글로 바꾼 새 문자열을 돌려줍니다.

위치를 찾는 함수는 두 가지입니다.

1. <strong>index</strong>는 없으면 오류가 나서 프로그램이 멈춥니다.
2. <strong>find</strong>는 없으면 `-1`을 돌려줍니다. 멈추면 안 될 때 이쪽이 안전합니다.

```python
index = python.index("n")
print(index)
index = python.index("n", index + 1)
print(index)

print(python.find("n"))
print(python.find("Java"))
print(python.count("n"))
```

첫 `n`은 `Python`의 끝입니다. 위치를 변수에 저장한 뒤, 그 다음 칸부터 다시 `index`를 호출하면 두 번째 `n`을 찾습니다. `count`는 그 글자가 몇 번 나오는지 셉니다. `Amazing` 안의 `n`까지 포함합니다.

`print(python.index("Java"))`는 `Java`가 없어서 오류입니다. 같은 상황을 `find`로 찾으면 `-1`만 출력되고 프로그램은 계속됩니다.

## 🦮 16. 문자열 포맷

문장 중간에 값을 끼워 넣는 방법이 네 가지 나옵니다. 결과는 같고, 적는 모양만 다릅니다.

방법 1은 `%`입니다. `%d`는 정수, `%s`는 문자열, `%c`는 문자 하나입니다. `%s`에는 숫자도 넣을 수 있습니다. 값이 두 개면 괄호로 묶습니다.

```python
print("나는 %d살입니다." % 20)
print("나는 %s을 좋아해요." % "파이썬")
print("Apple 은 %c로 시작해요." % "A")
print("나는 %s살입니다." % 20)
print("나는 %s색과 %s색을 좋아해요." % ("파란", "빨간"))
```

방법 2는 `format`과 중괄호입니다. 중괄호가 여러 개면 앞에서부터 값이 들어갑니다. `{0}`, `{1}`처럼 번호를 적으면 순서를 바꿀 수 있습니다.

```python
print("나는 {}살입니다.".format(20))
print("나는 {}색과 {}색을 좋아해요.".format("파란", "빨간"))
print("나는 {0}색과 {1}색을 좋아해요.".format("파란", "빨간"))
print("나는 {1}색과 {0}색을 좋아해요.".format("파란", "빨간"))
```

마지막 줄은 빨간 색이 먼저, 파란 색이 나중에 나옵니다. 값의 순서는 그대로이고, 중괄호 번호만 바뀌었기 때문입니다.

방법 3은 중괄호에 이름을 붙입니다. 호출하는 쪽에서 `age=20`처럼 이름을 지정하므로 순서가 바뀌어도 됩니다.

```python
print("나는 {age}살이며, {color}색을 좋아해요.".format(age=20, color="빨간"))
print("나는 {age}살이며, {color}색을 좋아해요.".format(color="빨간", age=20))
```

방법 4는 앞에 `f`를 붙이는 f-string입니다. 중괄호 안에 변수 이름을 그대로 적습니다. 지금 새로 짤 때는 이 모양이 가장 읽기 쉽습니다.

```python
age = 20
color = "빨간"
print(f"나는 {age}살이며, {color}색을 좋아해요.")
```

## 🦮 17. 탈출 문자

눈에 보이는 글자가 아닌 동작은 역슬래시로 적습니다.

| 문자 | 의미 |
| --- | --- |
| `\n` | 줄바꿈 |
| `\t` | 탭만큼 띄우기 |
| `\\` | 역슬래시 글자 자체 |
| `\"` `\'` | 따옴표 글자 자체 |
| `\r` | 커서를 그 줄의 맨 앞으로 이동 |
| `\b` | 바로 앞 글자 하나 지우기 |

```python
print("백문이 불여일견\n백견이 불여일타")
```

`\n` 자리에서 줄이 바뀝니다. 문장 안에 따옴표를 글자로 넣고 싶으면, 바깥 따옴표와 다른 종류를 쓰거나 역슬래시를 붙입니다.

```python
print("저는 '나도코딩'입니다.")
print('저는 "나도코딩"입니다.')
print("저는 \"나도코딩\"입니다.")
print("저는 \'나도코딩\'입니다.")
```

경로의 `\`는 탈출 문자로 오해될 수 있습니다. 글자 `\` 하나를 출력하려면 `\\`를 적습니다.

```python
print("C:\\Users\\Nadocoding\\Desktop\\PythonWorkspace")
```

`\r`은 커서를 줄 맨 앞으로 돌려, 앞에서 찍힌 글을 뒤에서 다시 덮어 씁니다.

```python
print("Red Apple\rPine")
```

`Red Apple`을 찍은 뒤 맨 앞으로 돌아와 `Pine`을 찍으므로, 명령 프롬프트에서는 `PineApple`처럼 보입니다. Visual Studio Code 출력창이나 다른 편집기에서는 이 덮어쓰기가 다르게 보일 수 있습니다. 결과가 영상과 달라도 문법 오류는 아닙니다.

```python
print("Redd\bApple")
print("Red\tApple")
```

`\b`는 `Redd`의 마지막 `d`를 지우고 `Apple`을 붙여 `RedApple`이 됩니다. `\t`는 탭 공백입니다.

## 🦮 18. Quiz. 사이트 비밀번호

사이트 주소로 비밀번호를 만듭니다. 규칙은 네 단계입니다.

1. `http://`를 뺍니다.
2. 처음 나오는 점 앞까지만 남깁니다. `naver.com`이면 `naver`입니다.
3. 남은 글자의 앞 세 글자, 글자 수, `e`의 개수를 이어 붙입니다.
4. 맨 뒤에 `!`를 붙입니다.

```python
url = "http://naver.com"
my_str = url.replace("http://", "")
my_str = my_str[:my_str.index(".")]
password = my_str[:3] + str(len(my_str)) + str(my_str.count("e")) + "!"
print("{0} 의 비밀번호는 {1} 입니다.".format(url, password))
```

`http://`를 빼면 `naver.com`입니다. `index(".")` 앞까지 자르면 `naver`입니다. 앞 세 글자는 `nav`, 길이는 5, `e`는 1개입니다. 비밀번호는 `nav51!`입니다.

`http://daum.net`으로 바꾸면 남는 글자는 `daum`입니다. 앞 세 글자 `dau`, 길이 4, `e`는 0개라 `dau40!`이 됩니다. 같은 규칙이 주소만 바꿔도 동작하는지 확인해 보면 됩니다.

다른 주소에도 같은 규칙을 적용하면 됩니다.

```python
url = "http://google.com"
my_str = url.replace("http://", "")
my_str = my_str[:my_str.index(".")]
password = my_str[:3] + str(len(my_str)) + str(my_str.count("e")) + "!"
print("{0} 의 비밀번호는 {1} 입니다.".format(url, password))
```

`google`은 앞 세 글자 `goo`, 길이 6, `e`가 1개라 `goo61!`입니다. `youtube`는 `you`, 길이 7, `e`가 0개라 `you70!`입니다.
