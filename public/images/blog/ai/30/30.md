## 🦮 클로드 코드로 2D·3D 영상 만드는 작업 환경

요즘 영상을 **클로드 코드(Claude Code)** 로 만들고 있습니다. 프로젝트 설명 영상(2D), 노래에 맞춘 뮤직비디오, 섬 위에서 AI들이 일하는 3D 설명 영상까지 모두 채팅으로 만들었습니다.

그런데 도구가 늘어나다 보니 **어떤 건 설치했고, 어떤 건 GitHub에서 받았고, 어디에 있는지**가 헷갈리기 시작했습니다. 그래서 흩어져 있던 도구와 작업 폴더를 `movie_create` 폴더 하나로 모으고, 설치부터 사용법까지 정리했습니다.

먼저 결론부터 말씀드리겠습니다.

1. **클로드는 영상을 직접 자르거나 그리지 않습니다.** FFmpeg, Whisper 같은 도구를 대신 실행해서 영상을 만듭니다. 그래서 도구를 먼저 깔아 두어야 합니다.

2. 2D와 3D는 **쓰는 도구와 스킬이 다릅니다.** 2D는 HTML로 화면을 짜는 **HyperFrames**, 3D는 **Blender로 모델을 만들고 three.js로 움직이는** 방식입니다.

3. 도구는 두 종류입니다. FFmpeg처럼 **컴퓨터에 설치하는 프로그램**은 어느 폴더에서든 실행되고, three.js처럼 **GitHub에서 받는 코드 묶음**은 폴더에 두고 클로드가 읽으면서 씁니다.

4. 모든 것을 `movie_create` 하나에 모아 두고, **그 폴더에서 클로드 코드를 열면** 2D든 3D든 바로 시작할 수 있습니다.

## 🦮 1. 준비물

| 항목 | 내용 |
|---|---|
| 클로드 요금제 | Pro 이상 (Claude Code를 쓰려면 유료 요금제가 필요합니다) |
| 운영체제 | Windows 10/11 기준으로 정리했습니다. macOS도 명령어만 다르고 흐름은 같습니다 |
| Python | 3.11 이상 (저는 3.12를 사용합니다) |
| Node.js | 22 이상 (HyperFrames가 22 이상을 요구합니다) |
| Git | GitHub에서 저장소를 받을 때 필요합니다 |
| 그래픽카드 | 2D는 없어도 됩니다. 3D와 뮤직비디오는 NVIDIA 그래픽카드가 있으면 훨씬 빠릅니다 |
| 디스크 | 10GB 정도 여유 공간 (Blender, three.js 저장소, Whisper 모델이 큽니다) |

도구는 모두 무료입니다. 단, **Remotion은 직원 4명 이상인 회사에서 쓰면 회사 라이선스가 필요합니다.** 개인, 3명 이하 회사, 비영리 단체는 무료입니다.

## 🦮 2. 폴더 구조

```text
movie_create/
├─ CLAUDE.md            ← 클로드가 처음 읽는 안내서 (어디에 뭐가 있는지)
├─ .claude/skills/      ← 스킬 모음 (HyperFrames, Remotion, lemo-opuscar)
├─ _tools/
│  ├─ ffmpeg-9.0.2/                 ← FFmpeg 실행 파일 사본
│  ├─ whisper-models/               ← Whisper 음성 인식 모델 (tiny, medium)
│  ├─ blender-5.3.0-windows-x64/    ← Blender (압축만 풀면 실행되는 버전)
│  ├─ mcp_addon.zip                 ← Blender MCP 애드온
│  └─ src/                          ← 도구들의 GitHub 원본 코드 (참고용)
│     ├─ FFmpeg_FFmpeg, openai_whisper, yt-dlp_yt-dlp
│     └─ remotion-dev_remotion, remotion-dev_skills, heygen-com_hyperframes
├─ 2d/
│  ├─ 레퍼런스/           ← 따라 하고 싶은 영상
│  ├─ 원본 영상/          ← 내가 찍은 영상, 녹음
│  ├─ 완성본/             ← 결과물이 저장되는 곳
│  └─ (프로젝트 폴더들)   ← 영상 하나당 HyperFrames 프로젝트 하나
└─ 3d/
   ├─ three.js/               ← 3D 그래픽 라이브러리
   ├─ react-three-rapier/     ← 물리 엔진 (부딪히고 떨어지는 움직임)
   ├─ react-postprocessing/   ← 빛 번짐, 그림자 같은 후처리 효과
   ├─ lemo-opuscar/           ← 코드로 영화를 만드는 스타일 라이브러리
   └─ (프로젝트 폴더들)       ← 영상 하나당 프로젝트 하나
```

2D 폴더의 `레퍼런스`, `원본 영상`, `완성본` 세 칸은 **넣는 곳, 재료, 나오는 곳**을 나눈 것입니다. 클로드에게 "레퍼런스 폴더의 영상처럼 만들어 줘"라고 말할 수 있어서 대화가 짧아집니다.

## 🦮 3. 도구 한눈에 보기

### 🦄 공통 도구 (2D·3D 모두 사용)

| 도구 | 하는 일 | 설치 방식 |
|---|---|---|
| FFmpeg | 컷 편집, 무음 찾기, 자막 입히기, 소리 합치기, 내보내기 | 프로그램 설치 (winget) |
| Whisper | 말소리를 받아 적어 자막 파일(SRT)과 단어별 시간 만들기 | 파이썬 패키지 (pip) |
| yt-dlp | 레퍼런스 영상 내려받기 | 파이썬 패키지 (pip) |
| Remotion | 코드(React)로 영상과 모션 그래픽 만들기 | 스킬 설치 (npx skills) |
| HyperFrames | HTML로 영상과 모션 그래픽 만들기 | 스킬 설치 + 실행할 때 자동 다운로드 (npx) |
| edge-tts | 대본을 한국어 음성(내레이션)으로 읽기 | 파이썬 패키지 (pip) |

### 🦄 3D 전용 도구

| 도구 | 하는 일 | 설치 방식 |
|---|---|---|
| Blender | 건물, 소품 같은 3D 모델 만들기 | 압축 파일 받아서 풀기 |
| Blender MCP | 클로드가 Blender를 직접 조작하게 연결 | Blender 애드온 + `claude mcp add` |
| three.js | 3D 장면, 카메라, 빛, 움직임을 코드로 만들기 | GitHub에서 받기 (git clone) |
| react-three-rapier | 물리 효과 (중력, 충돌) | GitHub에서 받기 |
| react-postprocessing | 빛 번짐(bloom), 그림자 같은 후처리 | GitHub에서 받기 |
| lemo-opuscar | 스타일 모음과 렌더·믹스 도구 (코드로 영화 만들기) | GitHub에서 받기 또는 플러그인 설치 |

### 🦄 왜 어떤 건 설치하고, 어떤 건 GitHub에서 받나요

제가 처음에 가장 헷갈렸던 부분입니다.

- **FFmpeg, Whisper, yt-dlp는 프로그램입니다.** 컴퓨터 전체에 한 번 설치하면 어느 폴더에서든 `ffmpeg` 한 단어로 실행됩니다. GitHub에도 원본 코드가 있지만, 받아도 직접 빌드(컴파일)해야 해서 오히려 번거롭습니다.
- **three.js, lemo-opuscar 같은 3D 쪽은 코드 묶음(라이브러리)입니다.** 실행 파일이 아니라 클로드가 **안의 코드와 예제를 읽으면서** 장면을 짜는 재료입니다. 그래서 작업 폴더 안에 받아 두는 것이 맞습니다.
- **Remotion과 HyperFrames는 그 중간입니다.** 프로그램 본체는 영상 프로젝트를 만들 때 자동으로 내려받고, 미리 깔아 두는 것은 클로드에게 **사용법을 알려 주는 스킬**입니다.

저는 한 폴더에 다 모아 두고 싶어서, 프로그램은 설치는 그대로 두고 `_tools`에 **실행 파일 사본과 GitHub 원본 코드(참고용)** 를 같이 넣어 두었습니다.

## 🦮 4. 설치하기

### 🦄 4-1. 기본 준비물

PowerShell을 열고 아래를 실행합니다. 이미 설치되어 있으면 건너뛰어도 됩니다.

```powershell
winget install Python.Python.3.12
winget install OpenJS.NodeJS.LTS      # 22 이상인지 꼭 확인
winget install Git.Git
winget install astral-sh.uv           # Blender MCP를 실행할 때 사용
```

### 🦄 4-2. 공통 도구 설치

```powershell
# 프로그램
winget install Gyan.FFmpeg
pip install -U openai-whisper yt-dlp edge-tts

# 스킬 (movie_create 폴더 안에서 실행해야 그 폴더에 설치됩니다)
cd C:\Users\<사용자>\Documents\movie_create
npx skills add remotion-dev/skills
npx skills add heygen-com/hyperframes
```

FFmpeg를 맨 앞에 두는 이유가 있습니다. **Whisper는 FFmpeg가 없으면 소리를 읽지 못하고, yt-dlp도 영상과 소리를 합칠 때 FFmpeg를 씁니다.** HyperFrames도 마지막에 MP4를 만들 때 FFmpeg를 씁니다.

하나씩 치기 귀찮다면, 클로드 코드에 아래 프롬프트를 그대로 붙여 넣어도 됩니다.

```text
아래 영상 편집 도구를 내 컴퓨터에 설치하고, 각각 제대로 실행되는지 버전을 확인해 줘.
- FFmpeg (winget install Gyan.FFmpeg)
- Whisper (pip install -U openai-whisper)
- yt-dlp (pip install -U yt-dlp)
- edge-tts (pip install -U edge-tts)
- Remotion 스킬 (npx skills add remotion-dev/skills)
- HyperFrames 스킬 (npx skills add heygen-com/hyperframes)

규칙
1. 이미 설치된 것은 건너뛰어 줘.
2. 설치 명령은 실행하기 전에 먼저 보여 줘.
3. Python이 없거나 Node.js가 22보다 낮으면 그것부터 설치하는 방법을 알려 줘.
4. 마지막에 도구별로 설치됨/실패와 버전을 표로 정리해 줘.
```

### 🦄 4-3. 3D 도구 설치

```powershell
cd C:\Users\<사용자>\Documents\movie_create\3d

# 3D 라이브러리 (GitHub)
git clone https://github.com/mrdoob/three.js.git
git clone https://github.com/pmndrs/react-three-rapier.git
git clone https://github.com/pmndrs/react-postprocessing.git
git clone https://github.com/lemomo-ai/lemo-opuscar.git

# lemo-opuscar가 쓰는 렌더·음성 도구 (Git Bash에서 실행)
sh lemo-opuscar/plugin/skills/lemo-opuscar/scripts/setup.sh deps
sh lemo-opuscar/plugin/skills/lemo-opuscar/scripts/setup.sh deps voice
```

three.js는 저장소가 커서 받는 데 시간이 걸립니다. 예제만 볼 거라면 `git clone --depth 1`로 최신 버전만 받아도 충분합니다.

**Blender와 Blender MCP**는 세 단계입니다.

1. blender.org에서 Windows용 **zip(포터블)** 버전을 받아 `_tools`에 풉니다. 설치 프로그램이 아니라서 폴더째 옮겨도 됩니다.
2. Blender를 켜고 **Edit → Preferences → Add-ons → Install from Disk**에서 `mcp_addon.zip`(Blender MCP 애드온)을 설치하고 켭니다.
3. 클로드 코드가 Blender에 말을 걸 수 있게 MCP 서버를 등록합니다.

```powershell
claude mcp add blender -s user -- uvx --from "git+https://projects.blender.org/lab/blender_mcp.git@v1.0.3#subdirectory=mcp" blender-mcp
```

`-s user`로 등록하면 어느 폴더에서 클로드를 열어도 Blender 도구가 보입니다. 단, **Blender가 켜져 있고 애드온이 연결된 상태**여야 동작합니다.

lemo-opuscar는 GitHub에서 받는 대신 **플러그인**으로 설치할 수도 있습니다. 이 경우 어느 폴더에서든 `/lemo-opuscar:lemo-opuscar`로 부를 수 있습니다.

```powershell
claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab
```

### 🦄 4-4. 설치 확인

**새 PowerShell 창**을 열고 실행합니다. 설치 직후 열려 있던 창에서는 FFmpeg가 안 잡힐 수 있습니다.

```powershell
ffmpeg -version
whisper --help
yt-dlp --version
node --version
npx hyperframes --version
claude mcp list        # blender: ... Connected 가 보이면 성공
```

> ✓ 성공하면 버전 번호가 출력되고, `claude mcp list`에 blender가 **Connected**로 나옵니다. 제 환경은 FFmpeg 9.0.2, Whisper 20250625, yt-dlp 2026.10.26, Node.js 22, HyperFrames 0.9.31, Blender 5.3입니다.

### 🦄 사용하는 스킬

| 스킬 | 언제 쓰나 |
|---|---|
| `/hyperframes` | **2D 영상의 시작점.** 영상 만들기, 수정, 렌더링 전부 여기서 시작합니다 |
| `/hyperframes-cli` | 프로젝트 만들기, 검사(check), 프레임 미리 보기(snapshot), 렌더링 명령 |
| `/hyperframes-registry` | 전환 효과, 자막 스타일, 차트 같은 완성 부품 약 450개 |
| `/media-use` | 음악, 효과음, 이미지, 내레이션, 자막(Whisper), 색 보정 |
| `/reverse-any-video` | 레퍼런스 영상을 그대로 다시 만들어 보기 |
| `/style-sampling` | 정해진 스타일(콜라주, 금융 설명 등)로 내 주제의 영상 만들기 |
| `/figma` | 피그마 디자인, 로고를 영상에 가져오기 |
| `/slideshow` | 영상이 아니라 발표용 슬라이드로 만들기 |
| `/remotion-*` | Remotion(React)으로 만들 때. 자막, 렌더, 지도 등 13개 |
| `/remotion-to-hyperframes` | Remotion으로 만든 영상을 HyperFrames로 옮기기 |

대부분은 **`/hyperframes` 하나만 부르면** 클로드가 필요한 스킬을 알아서 이어서 씁니다. HyperFrames와 Remotion은 하는 일이 비슷한데, 저는 브라우저에서 바로 미리 보고 고칠 수 있는 HyperFrames를 주로 씁니다.

### 🦄 작업 흐름

1. **레퍼런스 넣기:** 따라 하고 싶은 영상 주소를 주면 yt-dlp로 `레퍼런스` 폴더에 받습니다.
2. **스타일 뽑기:** FFmpeg로 장면을 잘라 보고, Whisper로 말투를 받아 적어 `스타일.md`에 색, 글꼴, 자막 위치, 말 빠르기를 정리합니다.
3. **대본 쓰기:** 장면별로 "말할 문장"과 "화면에 보일 것"을 나눠 씁니다.
4. **내레이션 만들기:** edge-tts로 대본을 읽히고, 문장마다 시작·끝 시간을 기록합니다. 화면은 이 시간에 맞춰 움직입니다.
5. **장면 만들기:** 장면 하나를 HTML 파일 하나로 만들고, 움직임은 GSAP 타임라인으로 넣습니다.
6. **검사와 미리 보기:** `npx hyperframes check`로 글자 겹침, 대비, 오류를 검사하고 `snapshot`으로 원하는 초의 화면을 PNG로 뽑아 확인합니다.
7. **렌더링:** `npx hyperframes render`로 MP4를 만들어 `완성본`에 저장합니다.

10분이 넘는 영상은 렌더링이 오래 걸립니다. `--workers 3`처럼 **동시 작업 수**를 올리면 빨라지지만 메모리를 많이 씁니다. 메모리가 부족해서 렌더링이 중간에 꺼지면 숫자를 1로 낮춥니다.

### 🦄 프롬프트 예시

**① 레퍼런스로 스타일 알려 주기**

```text
레퍼런스 폴더에 있는 영상 3개를 보고 공통 스타일을 정리해서 레퍼런스/스타일.md로 저장해 줘.
색, 글꼴, 자막 위치, 장면 전환 방식, 말 빠르기를 표로 정리하고,
이후 영상은 이 스타일을 기준으로 만들어 줘.
```

**② 영상 맡기기**

```text
아래 GitHub 저장소 내용을 다 확인하고, 레퍼런스 스타일대로 16:9 설명 영상을 만들어 줘.
기술적인 설명은 빼고, 남성 내레이션과 자막을 넣어 줘.
완성본은 2d/완성본 폴더에 저장해 줘.
```

**③ 채팅으로 고치기**

```text
3분 20초 장면에서 숫자가 카드 밖으로 넘쳐. 글자 크기를 줄이고,
오른쪽 위 도장이 제목이랑 겹치는 것도 아래로 옮겨 줘. 고친 장면만 스냅샷으로 보여 줘.
```

### 🦄 뮤직비디오는 조금 다릅니다

노래에 맞춘 영상은 **가사 타이밍**이 핵심입니다.

1. Whisper로 노래를 받아 적어 **단어별 시간**을 얻습니다.
2. 받아 적은 글이 실제 가사와 조금씩 다르기 때문에, 원래 가사와 맞춰서 줄마다 시작 시간을 정합니다.
3. 소리의 크기와 박자를 분석해서 불꽃이 터지는 순간, 화면 밝기 같은 움직임을 음악에 맞춥니다.
4. 영상 길이를 **노래 길이와 똑같이** 맞추고, FFmpeg로 영상과 음원을 합칩니다.

한 가지 막혔던 점이 있습니다. FFmpeg의 NVIDIA 하드웨어 인코딩(`h264_nvenc`)은 **그래픽 드라이버가 오래되면 동작하지 않습니다.** 이럴 때는 CPU 인코딩(`libx264`)으로 바꾸면 조금 느리지만 문제없이 만들어집니다.

## 🦮 7. 3D 영상 만들기

<img src="/images/blog/ai/30/images2.webp"/>

### 🦄 사용하는 스킬과 도구

| 이름 | 종류 | 언제 쓰나 |
|---|---|---|
| `/lemo-opuscar` | 스킬 | **3D 영상의 시작점.** 스타일 고르기, 트리트먼트(연출 계획), 제작, 렌더링까지 안내합니다 |
| Blender MCP | MCP 도구 | 클로드가 Blender에서 건물, 소품을 직접 모델링하고 GLB 파일로 내보냅니다 |
| three.js | 라이브러리 | 장면, 카메라, 빛, 시간에 따른 움직임을 코드로 짭니다 |
| react-three-rapier | 라이브러리 | 떨어지고 부딪히는 물리 움직임이 필요할 때 |
| react-postprocessing | 라이브러리 | 빛 번짐, 그림자 같은 후처리 효과를 참고할 때 |
| `/hyperframes` | 스킬 | 3D 장면 위에 자막, 제목 카드를 얹거나 HTML 안에서 3D를 쓸 때 |
| `/media-use` | 스킬 | 내레이션, 효과음, 음악 |

lemo-opuscar에는 **로우폴리 섬, 유화, 수채화, 우키요에, 청사진** 같은 스타일이 수십 개 들어 있습니다. 저는 "로우폴리 아이소메트릭 섬" 스타일을 골랐습니다.

### 🦄 작업 흐름

1. **트리트먼트 쓰기:** 영상 구조 후보 3개를 놓고 하나를 고른 뒤, 장면별 카메라와 이유를 `TREATMENT.md`에 적습니다. 3D는 다시 만드는 비용이 커서 이 단계를 꼭 먼저 합니다.
2. **모델 만들기:** Blender MCP로 건물, 서버 랙, 감시탑 같은 소품을 모델링하고 `kit.glb` 한 파일로 내보냅니다.
3. **장면 짜기:** three.js로 섬을 깔고 모델을 배치합니다. 핵심은 **화면이 시간의 함수**라는 점입니다. `render(t)`에 같은 시간을 넣으면 언제나 같은 화면이 나와야 렌더링이 흔들리지 않습니다.
4. **내레이션과 자막:** edge-tts로 음성을 만들고, 문장 시간에 맞춰 자막(SRT)과 장면 타임라인을 만듭니다.
5. **렌더링:** 보이지 않는 크롬 브라우저(Playwright)가 프레임을 한 장씩 찍어 영상으로 만듭니다.
6. **소리 합치기:** 음악, 효과음, 내레이션을 섞고 FFmpeg로 영상과 합칩니다.

저는 이 과정을 `build.sh` 한 파일에 묶어서, 대본을 고치면 `sh build.sh` 한 번으로 처음부터 다시 만들 수 있게 했습니다.

### 🦄 프롬프트 예시

```text
/lemo-opuscar 로우폴리 섬 스타일로 3분 정도 설명 영상을 만들어 줘.
주제는 결제 장애가 나면 AI 아홉 개가 일을 나눠 처리하는 과정이야.
건물과 소품은 Blender MCP로 직접 만들고, 한국어 남성 내레이션과 자막을 넣어 줘.
시작하기 전에 트리트먼트부터 보여 줘.
```

```text
5번 장면에서 카메라가 너무 빨리 돌아. 회전을 절반 속도로 줄이고,
서버 랙이 빠져나오는 순간 직전에 1초 정도 멈춰 줘.
```

## 🦮 8. 2D와 3D 한눈에 비교

| 구분 | 2D | 3D |
|---|---|---|
| 시작 스킬 | `/hyperframes` | `/lemo-opuscar` |
| 화면을 만드는 방법 | HTML + CSS + GSAP | three.js + Blender 모델(GLB) |
| 모델링 | 필요 없음 | Blender MCP |
| 렌더링 | `npx hyperframes render` | 헤드리스 크롬으로 프레임 촬영 → FFmpeg |
| 미리 보기 | 브라우저 미리 보기, `snapshot` | 프레임 스틸 뽑기 |
| 기본 해상도 | 1920×1080, 30fps | 1920×1080, 24fps |
| 잘 맞는 영상 | 설명 영상, 발표 영상, 자막 많은 영상 | 세계관, 공간, 흐름을 보여 주는 영상 |
| 제작 시간 | 짧음 | 김 (모델링과 렌더링이 오래 걸림) |

정보를 많이 전달해야 하면 **2D**, 한 장면으로 분위기와 구조를 보여 줘야 하면 **3D**가 맞았습니다.

## 🦮 9. 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| `ffmpeg`를 찾을 수 없음 | 설치 직후 열려 있던 터미널이라 그렇습니다. 새 창을 엽니다 |
| `h264_nvenc` 오류 | 그래픽 드라이버가 오래되었습니다. `libx264`로 바꾸거나 드라이버를 업데이트합니다 |
| 렌더링이 중간에 꺼짐 | 메모리 부족입니다. `--workers`를 1~2로 낮춥니다 |
| 스킬이 안 보임 | 클로드를 `movie_create`가 아닌 다른 폴더에서 열었습니다 |
| Blender 도구가 동작하지 않음 | Blender가 꺼져 있거나 애드온 연결이 끊겼습니다. Blender를 켜고 애드온을 다시 연결합니다 |
| 폴더를 옮긴 뒤 파이썬 도구가 안 됨 | 가상환경(`.venv`)은 경로가 바뀌면 깨집니다. `setup.sh deps`를 다시 실행합니다 |
| 음성 파일 합치기 실패 | 상대 경로 문제입니다. 프로젝트 폴더의 전체 경로로 실행합니다 |

메뉴 위치나 화면은 버전에 따라 바뀔 수 있습니다.
