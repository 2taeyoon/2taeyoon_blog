## 🦮 해커톤 우승자가 만든 클로드 코드 플러그인 ECC, 설치부터 사용법까지

**ECC(Everything Claude Code)** 는 앤트로픽 해커톤 우승자라고 밝힌 개발자가 공개한 클로드 코드 플러그인입니다. 설치 명령 두 줄이면 클로드 코드에 **에이전트 72개, 스킬 327개, 명령어 98개**가 한 번에 들어옵니다.

저도 이 블로그를 관리하는 클로드 코드에 직접 설치해서 쓰고 있어서, 설치 방법과 함께 실제로 써 보며 느낀 점을 정리했습니다.

먼저 결론부터 말씀드리겠습니다.

1. ECC는 **클로드 코드 전용 무료 플러그인**입니다. claude.ai 웹이나 앱의 일반 대화창에서는 쓸 수 없습니다.

2. 설치는 클로드 코드 안에서 **명령 두 줄**이면 끝납니다.

3. 설치하면 클로드가 바로 코드를 쓰지 않고 **계획 → 테스트 → 구현 → 검토 → 확인** 순서로 일하도록 작업 습관이 바뀝니다.

4. 앤트로픽 공식 제품이 아닌 개인 오픈소스라 **이름만 같은 복사본**이 많습니다. 반드시 공식 경로로만 설치해야 합니다.

---

## 🦮 1. ECC가 무엇인가요

ECC는 클로드 코드 위에 얹어 쓰는 **플러그인(확장 도구)** 입니다. GitHub에서 별을 30만 개 넘게 받은 저장소이고, MIT 라이선스로 무료 공개돼 있습니다.

| 항목 | 내용 |
|---|---|
| 동작 환경 | 클로드 코드 (터미널, 데스크톱 앱, IDE 확장) |
| 요금 | 플러그인은 무료. 클로드 코드는 Pro 이상 유료 요금제 필요 |
| 라이선스 | MIT |
| 공식 경로 | 저장소 `github.com/affaan-m/ECC`, 사이트 `ecc.tools`, 플러그인 이름 `ecc@ecc` |

---

## 🦮 2. 설치 방법: 명령 두 줄

### 🦄 1단계: 마켓플레이스 등록

터미널에서 `claude`를 입력해 클로드 코드를 켠 뒤, 입력창에 아래 명령을 붙여 넣고 Enter를 누릅니다. ECC 저장소를 플러그인 목록(마켓플레이스)에 등록하는 단계입니다.

```text
/plugin marketplace add https://github.com/affaan-m/ECC
```

### 🦄 2단계: 플러그인 설치

같은 방법으로 두 번째 명령을 넣으면 ECC가 설치됩니다.

```text
/plugin install ecc@ecc
```

### 🦄 3단계: 설치 확인

클로드 코드를 껐다가 다시 켠 뒤 아래 명령을 입력합니다. 목록에 `ecc@ecc`가 켜져 있으면 설치가 끝난 것입니다.

```text
/plugin list
```

명령을 직접 치기 낯설다면, 아래 부탁을 통째로 보내도 됩니다. 클로드가 두 명령을 차례로 실행하고 결과를 알려 줍니다.

```text
ECC 플러그인을 공식 저장소에서 설치해 줘.
아래 두 명령을 차례로 실행하고, 끝나면 /plugin list로 ecc@ecc가 켜져 있는지 확인해 줘.
/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc
```

### 🦄 터미널이 익숙하다면: 안내형 설치

Node.js 18 이상이 깔려 있다면, 클로드 코드 밖의 터미널에서 안내형 설치 도구를 쓸 수도 있습니다. 어느 범위(내 계정 전체, 이 프로젝트만)에 깔지와 훅 강도를 물어보고, 이미 깔린 것이 있으면 정리한 뒤 설치해 줍니다.

```bash
npx ecc-universal@2.2.3 setup
```

개인용이라면 **Global user**와 **Standard** 훅을 고르면 됩니다.

## 🦮 3. 한 번에 들어오는 것

| 구성 | 개수 | 하는 일 |
|---|---|---|
| 에이전트 | 72개 | 기획, 코드 리뷰, 빌드 오류 수정, 보안 점검, 설계처럼 일을 나눠 맡는 보조 |
| 스킬 | 327개 | 테스트, 조사, 문서, 디자인, 데이터, 마케팅까지 "일 잘하는 방법"을 적어 둔 설명서 |
| 명령어 | 98개 | `/ecc:plan`처럼 바로 불러 쓰는 단축 명령 |
| 기억·훅 | 포함 | 정해진 순간에 자동으로 도는 규칙(훅)으로 작업 요약을 남기고, 잘된 방식을 다음 작업에 다시 활용 |
| AgentShield | 포함 | 프롬프트, 설정, 비밀 키가 새는 곳을 찾는 보안 검사 |

제 컴퓨터에 설치된 2.2.3 버전 폴더에서 직접 세어 봐도 에이전트 72개, 스킬 327개, 명령어 98개로 같았습니다.

## 🦮 4. 직접 써 보니 이렇게 달라졌습니다

가장 먼저 체감한 것은 **훅**입니다. ECC를 깐 뒤 이 블로그 글을 쓰는 중에, 클로드가 첫 터미널 명령을 실행하려고 하자 ECC의 "사실 확인 관문(Fact-Forcing Gate)" 훅이 이렇게 막아 세웠습니다.

```text
[Fact-Forcing Gate]
Before the first Bash command this session, present these facts:
1. The current user request in one sentence
2. What this specific command verifies or produces
```

새 파일을 만들 때도 마찬가지였습니다. 비슷한 문서가 이미 있는지 검색해 보고, 어디서 연결될 파일인지, 왜 기존 파일을 고치지 않고 새로 만드는지, 그리고 제 요청 원문을 그대로 적은 뒤에야 파일을 만들 수 있었습니다.

처음에는 한 번 더 거치는 게 번거롭게 느껴졌습니다. 그런데 이 과정 덕분에 클로드가 **요청을 다시 확인하고 중복 파일을 만들지 않는** 습관이 자동으로 생겼습니다. 사람이 매번 "확인하고 해"라고 말하지 않아도 규칙이 대신 챙겨 주는 셈입니다.

## 🦮 5. 바로 써 볼 수 있는 부탁

명령어로 불러도 되고, 평소처럼 한국어로 부탁해도 됩니다. 부탁 내용에 맞는 스킬을 클로드가 알아서 골라 씁니다. `OO` 부분만 내 내용으로 바꿔 보세요.

**만들기 전에 계획부터 받기**

```text
/ecc:plan "OO 예약 페이지 만들기"
```

**내 글 말투 익히게 하기 (brand-voice)**

```text
아래에 내가 직접 쓴 글 3개를 붙여 넣을게.
이 글들의 말투와 문장 습관을 정리해 두고, 앞으로 내가 부탁하는 글은 이 말투로 써 줘.
```

**경쟁 서비스 비교표 받기 (market-research)**

```text
OO 분야에서 경쟁하는 서비스 5곳을 조사해서 가격, 강점, 약점을 표로 비교해 줘.
각 내용마다 출처 링크도 붙여 줘.
```

**출시 캠페인 짜기 (marketing-campaign)**

```text
이번에 새로 내는 OO의 출시 캠페인을 짜 줘.
누구에게 팔지, 핵심 메시지 한 줄, 인스타그램 게시물 문구 3개까지 정리해 줘.
```

**글 하나로 여러 채널용 콘텐츠 만들기 (content-engine)**

```text
아래 글 하나로 인스타그램 게시물, 유튜브 쇼츠 대본, 뉴스레터 글을 각각 만들어 줘.
```

**검색 노출 개선점 찾기 (seo)**

```text
내 홈페이지 주소는 OO야. 검색에 더 잘 걸리도록 고칠 점을 중요한 순서대로 정리해 줘.
```

## 🦮 7. 주의할 점: 공식 경로로만 설치하기

ECC는 인기가 많은 만큼 **이름만 같은 복사본**이 많습니다. 만든 사람도 비공식 복사본에 악성 코드가 들어 있을 수 있다고 경고합니다. 아래 세 가지가 모두 맞는지 확인하고 설치하세요.

- 저장소: `github.com/affaan-m/ECC`
- 공식 사이트: `ecc.tools`
- 플러그인 이름: `ecc@ecc`

## 🦮 8. 막혔을 때

### 🦄 "이미 설치돼 있다"거나 범위가 겹친다는 오류가 날 때

클로드 코드 플러그인은 **내 계정 전체(user), 이 프로젝트(project), 내 컴퓨터의 이 프로젝트만(local)** 세 범위 중 한 곳에 깔립니다. 예전에 다른 범위에 깔아 둔 것이 있으면 겹친다는 오류가 납니다. 이때는 그 위에 또 설치하지 말고, 안내형 설치 도구를 실행해서 한 범위로 정리합니다.

```bash
npx ecc-universal@2.2.3 setup
```

### 🦄 최신 버전으로 바꾸고 싶을 때

같은 안내형 설치 명령을 다시 실행하면 업데이트됩니다. 설치 범위나 훅 강도를 바꿀 때도 같은 명령을 씁니다.

### 🦄 지우고 싶을 때

설치했던 폴더에서 먼저 미리보기로 무엇이 지워지는지 확인한 뒤 삭제합니다.

```bash
npx ecc-universal@2.2.3 uninstall --dry-run
npx ecc-universal@2.2.3 uninstall
```
