## 🦮Warp이란?

>Warp는 AI 에이전트와 함께 개발하기 위한 터미널 환경을 강조하는 제품입니다. 공식 사이트에서는 여러 코딩 에이전트(예: Claude Code, Codex, Gemini CLI, OpenCode 등)를 터미널에서 함께 다룰 수 있다는 점을 소개하고 있습니다. 저는 이번 글에서 공식 홈페이지를 기준으로 **설치**, **기본 사용법**, **공식 페이지에 나오는 UI 예시**, 그리고 Windows PowerShell에서 자주 맞닥뜨리는 **실행 정책** 문제까지 정리해 보겠습니다.

## 🦮Warp 설치하기

OS에 맞는 설치 방법을 선택하시면 됩니다. 공식 다운로드 페이지에서 설치 파일을 받으실 수 있으며, 패키지 매니저를 쓰시는 경우 아래와 같은 명령으로 설치하실 수도 있습니다.

**macOS (Homebrew)**

```bash
brew install --cask warp
```

**Windows (winget)**

```bash
winget install Warp.Warp
```

설치가 끝나신 뒤에는 Warp를 실행하시고, 사용 중이시던 셸(예: PowerShell, WSL 등)을 그대로 이어서 쓰시면 됩니다. 패키지별 설치 파일과 아키텍처(x64, ARM64)는 Warp 다운로드 페이지에서 확인하실 수 있습니다.

## 🦮Warp 기본 사용법

**1. 작업 폴더(워크스페이스) 열기**  
처음이시라면 메뉴에서 프로젝트 루트 폴더를 여시면 됩니다. 이후에도 동일하게 폴더를 바꾸시면서 여러 저장소를 오가실 수 있습니다.

**2. 블록 단위 출력**  
Warp는 명령 한 번에 대응하는 출력을 하나의 **블록**으로 묶어 보여 줍니다. 블록 단위로 스크롤·복사·다시 실행하기가 수월해서, 긴 빌드 로그를 다루실 때도 읽기 편한 편입니다.

**3. 설정과 명령 팔레트**  
테마·폰트·셸 연동 등은 설정에서 조정하실 수 있고, 기능 검색은 명령 팔레트에서 찾아보실 수 있습니다. 단축키는 OS·버전에 따라 달라질 수 있으니, 최신 안내는 Warp 문서를 함께 참고해 주시기 바랍니다.

**4. AI 에이전트와 워크플로**  
공식 소개에 따르면, 터미널 안에서 **여러 코딩 에이전트**를 함께 쓰실 수 있고, 프로젝트 맥락을 잡은 뒤 **할 일 목록**을 제안받는 흐름이 강조됩니다. 또한 기능 구현·버그 수정·운영 디버깅·코드베이스 이해처럼 목적에 맞는 **워크플로**를 고르고 시작하실 수 있다고 안내하고 있습니다.

## 🦮Windows에서 `cursor-agent` 실행 시 스크립트가 막히는 경우

Warp 안에서 PowerShell을 쓰시다가 `cursor-agent` 같은 명령을 실행하셨을 때, 아래와 비슷한 메시지가 나오실 수 있습니다. **실행 정책(Execution Policy)** 때문에 `.ps1` 스크립트를 불러오지 못하는 경우입니다.

<img src="/images/blog/ai/6/image1.webp"/>

메시지 요지는 “이 시스템에서는 스크립트 실행이 제한되어 있어 `cursor-agent.ps1`을 로드할 수 없다”는 내용이며, `PSSecurityException`으로 분류됩니다.

***

## 🦮실행 정책을 CurrentUser 범위에서 완화하기

보통은 **현재 사용자** 범위에서만 정책을 조정하시면 충분합니다. 아래 명령을 PowerShell에 입력해 주십시오.

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

실행하시면 보안 안내와 함께 변경 여부를 묻는 프롬프트가 나옵니다. 로컬에서 작성하신 스크립트는 실행하실 수 있고, 인터넷에서 받은 스크립트는 신뢰할 수 있는 서명이 있어야 한다는 의미의 **RemoteSigned**입니다. 동의하실 때는 `Y`를 입력해 주시면 됩니다.

<img src="/images/blog/ai/6/image2.webp"/>

## 🦮설정이 반영되었는지 확인하기

적용 여부는 아래 명령으로 확인하실 수 있습니다.

```powershell
Get-ExecutionPolicy -List
```

`CurrentUser` 항목에 `RemoteSigned`가 표시되시면, 해당 범위에서는 의도하신 정책이 반영된 것입니다.

<img src="/images/blog/ai/6/image3.webp"/>

조직 정책으로 **MachinePolicy**나 **UserPolicy**가 별도로 잡혀 있는 환경에서는 위 설정만으로 부족할 수 있으니, 그때는 IT 정책을 확인해 주시기 바랍니다.

## 🦮마무리

Warp는 터미널 사용 경험을 바꾸는 동시에, Windows에서는 PowerShell **실행 정책** 같은 OS 쪽 설정과도 맞닥뜨리실 수 있습니다. 설치·기능 개요는 <a href="https://www.warp.dev/" target="_blank">Warp 공식 홈페이지</a>와 <a href="https://docs.warp.dev/" target="_blank">공식 문서</a>를 참고하시고, 스크립트 실행 오류가 나오시면 이번에 정리한 순서대로 **범위를 CurrentUser로 한정**해 조정·확인해 보시면 대부분 해결되실 겁니다. 이후에는 Warp 안에서 에이전트 기능을 천천히 익혀 가시면서, 팀 규칙과 보안 요구사항에 맞게 사용 범위를 정하시면 좋겠습니다.
