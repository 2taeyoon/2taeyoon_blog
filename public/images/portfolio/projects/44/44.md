## Overview

대한화상학회는 화상 진료와 연구를 다루는 학회입니다. 홈페이지에서는 학술대회 사전등록과 후원업체 등록, 비회원 등록조회를 지원하고, 인증의제도 안내와 인증의 검색, 화상 전문 병원 찾기 기능을 제공합니다.

## Work

팀 프로젝트로 학회 공식 홈페이지의 반응형 퍼블리싱과 프론트엔드 개발에 참여했습니다.

### 메인 화면

- jQuery와 Swiper·slick·bxSlider로 메인 비주얼, 공지사항 최신글, 등록 중인 학술대회, Journal 바로가기, 후원사 슬라이더를 구현했습니다.

### 학술대회 등록과 조회

- 등록 중인 행사 상세에 후원 안내와 약정서 다운로드를 넣었습니다.
- 사전등록·후원업체 등록 신청 폼과 등록 확인 화면을 만들고 필수값 유효성 검사와 개인정보 동의를 처리했습니다.
- 비회원 등록조회 화면에서 연도·행사를 고르고 이름·비밀번호를 입력하면 영수증과 이수증을 출력하도록 작업했습니다.
- 학술행사 일정의 목록형/월별·3개월 달력형 전환과 엑셀 다운로드, 지난 학술대회 검색과 PDF 다운로드를 구현했습니다.

### 인증의제도와 검색

- 자격인정 단계 안내와 서식 다운로드 화면을 만들고, 응시원서 접수·응시 확인·자격갱신은 회원 전용 메뉴로 접근을 처리했습니다.
- 학회 인증의 검색, 지역 셀렉트와 병원명으로 찾는 화상 전문 병원 찾기, 회원검색 화면을 구현했습니다.

### 게시판과 회원 화면

- 회원공간·자료실 게시판의 목록, 상세, 검색 화면을 작업하고 행사 갤러리의 접근을 처리했습니다.
- 로그인과 회원가입 안내 화면을 만들었습니다.
