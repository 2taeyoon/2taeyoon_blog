## Overview

netmarble은 넷마블 공식 사이트를 보고 헤더, 메인 슬라이더, 서비스 목록을 똑같이 만들어 본 클론 코딩 프로젝트입니다. 적응형 웹이라서 PC 화면과 모바일 화면을 따로 구성했습니다.

## Work

### 헤더와 내비게이션

- 헤더와 내비게이션 바는 PC용과 모바일용을 각각 만들어 화면 크기에 맞는 쪽이 보입니다.
- 상단 메뉴에는 서브 메뉴와 언어 선택 기능을 넣었습니다.

### 메인 슬라이더

- 메인 페이지 슬라이드는 이미지와 텍스트로 구성했습니다.
- 버튼이나 슬라이드 박스를 누르면 다음 콘텐츠로 넘어갑니다.

### 서비스 목록

- 상세 페이지에 게임 서비스 목록을 만들고 게임마다 아이콘과 텍스트로 정보를 정리했습니다.
