## Overview

netmarble은 실제 사이트 구조와 화면을 기준으로 만든 클론입니다. PC와 모바일에서 헤더, 서브 메뉴, 언어 선택, 메인 슬라이더, 게임 정보 목록이 각자 맞게 보이도록 나눴습니다.

## Approach

- 적응형 레이아웃으로 PC와 모바일 화면을 분리
- Swiper로 메인 슬라이드의 이미지와 문구를 넘김
- 상세 목록은 아이콘과 텍스트로 게임 정보를 정리
