## Overview

Amber Flux는 빠르게 변하는 상태를 따뜻한 색과 부드러운 피드백으로 전달하는 디지털 프로토타입입니다.

## Challenge

화면 전환이 잦아도 사용자가 현재 위치와 다음 행동을 놓치지 않도록 일관된 피드백 규칙이 필요했습니다.

## Approach

- 주요 사용자 흐름을 작은 상태 단위로 분리
- 색상보다 형태와 위치를 우선하는 상태 표현
- 애니메이션의 시작과 종료 시점을 입력 흐름에 맞게 조정

## Key Features

### Immediate feedback

선택, 전환, 완료 상태를 짧은 모션과 명확한 텍스트 변화로 함께 전달했습니다.

### Reusable prototype

콘텐츠 데이터와 화면 컴포넌트를 분리해 다른 시나리오도 같은 인터랙션 규칙으로 검증할 수 있습니다.

## Outcome

빠른 프로토타이핑 과정에서도 접근성과 일관성을 유지할 수 있는 인터랙션 기준을 마련했습니다.
