## Overview

(사)창의공학연구원 홈페이지는 CLA 고위자 과정과 창의미래포럼, 동문 활동을 안내하는 공식 사이트입니다. 과정 원서 신청과 포럼 등록을 사이트에서 받습니다.

## Work

운영 중인 창의공학연구원 홈페이지의 유지보수로 참여해 과정 안내와 신청 화면을 수정했습니다.

### 원서 신청과 포럼 안내
- CLA 고위자 과정 기수별 일시·장소·등록기간 안내를 모집 일정에 맞춰 업데이트했습니다.
- 원서 신청·창의미래포럼 등록 폼의 입력 항목을 변경하고 유효성 검사를 보완했습니다.

### 콘텐츠와 게시판
- 강의 구성·주요 강사진 페이지 내용과 브로슈어 자료를 교체했습니다.
- 보도자료·동문 게시판의 목록·상세 화면 오류와 반응형 레이아웃 깨짐을 수정했습니다.
