## Overview

대한보건의료정보관리학회 공식 홈페이지의 유지보수로 참여해 콘텐츠 업데이트와 화면 수정을 맡았습니다. 진행중인 학술행사와 초록접수 폼, 행사일정 캘린더, 온라인 논문투고 시스템 연계 화면 등을 다뤘습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 대한보건의료정보관리학회 홈페이지의 학술행사 안내와 화면을 수정했습니다.

### 학술행사와 초록접수
- 학술행사 개최안내와 진행중인 학술행사 목록을 행사 일정에 맞춰 업데이트했습니다.
- 초록접수 폼의 입력 항목을 변경하고 유효성 검사를 보완했습니다.

### 메인과 학회지
- 메인 비주얼 슬라이드와 팝업을 교체 등록했습니다.
- 학회지 규정 페이지 내용을 수정하고 공지사항·자료실 게시판의 목록·상세 화면 오류를 수정했습니다.
