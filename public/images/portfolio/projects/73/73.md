## Overview

대한외과여자의사회의 위원회, 전국네트워크, 학술행사 정보를 제공하는 공식 홈페이지입니다. 운영 중인 사이트에서 후원업체 등록·신문고 폼과 일정, 회원 검색 화면을 유지보수했습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 대한외과여자의사회 홈페이지의 퍼블리싱과 프론트엔드 작업을 진행했습니다.

### 메인 화면
- Swiper 메인 비주얼, 위원회 바로가기, 공지/회원소식 탭, 뉴스레터 영역, 레이어 팝업을 작업했습니다.

### 신청·상담 폼
- 회사명·담당자·연락처·세금계산서 요청일 입력, 파일 첨부, 사업자등록증·통장사본 다운로드, 유효성 검사를 갖춘 후원업체 등록 폼을 구현했습니다.
- 신청기간 외 안내 처리를 적용했습니다.
- 분류 선택, 성함·이메일·상담내용 입력, 동의 체크, 자동입력방지, 카카오 우편번호 검색 연동을 포함한 신문고 상담 폼을 작업했습니다.

### 학술행사와 회원
- 학술·행사 일정의 목록/달력 전환과 엑셀 다운로드, 지난학술대회 연·월 필터를 구현했습니다.
- 회원/비회원을 선택하고 비회원 입력에 유효성 검사를 적용한 사전등록 화면을 작업했습니다.
- 이름·이메일로 찾는 회원 명단 검색과 가입안내·회비 안내 페이지를 구성했습니다.

### 게시판
- 권역별 전국네트워크 게시판과 동호회·자료실·학회소식·회원소식 게시판의 목록/상세/검색을 작업했습니다.
- 로그인과 아이디/비밀번호 찾기 화면을 구현했습니다.
