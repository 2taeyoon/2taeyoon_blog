## Overview

대한비만연구의학회 공식 홈페이지의 유지보수로 참여해 콘텐츠 업데이트와 화면 수정을 맡았습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 대한비만연구의학회 홈페이지의 세미나 안내와 폼 화면을 수정했습니다.

### 세미나와 신청 폼
- 진행중인 세미나 목록·상세 안내를 일정에 맞춰 업데이트했습니다.
- 학술행사 후원신청·사회공헌 참여하기 폼의 입력 항목을 변경하고 유효성 검사를 보완했습니다.

### 메인과 게시판
- 메인 비주얼 슬라이드와 레이어 팝업을 교체 등록했습니다.
- 학술자료실·웹진·초빙공고 게시판의 목록·상세 화면 오류를 수정했습니다.
