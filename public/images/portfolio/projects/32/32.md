## Overview

대한회복기재활학회는 회복기 재활 분야의 학회입니다. 홈페이지에서는 학회소식과 행사 캘린더를 보여 주고, 진행 중인 학술행사의 사전등록과 비회원 등록 조회를 지원합니다.

## Work

팀 프로젝트로 학회 공식 홈페이지의 반응형 퍼블리싱과 프론트엔드 개발에 참여했습니다.

### 메인 화면

- 이전/다음 버튼과 카운터가 있는 Swiper 메인 비주얼을 구현했습니다.
- 학회소식·공지 최신글 탭, 행사 캘린더, 회원검색 바로가기 영역을 만들고 AOS 스크롤 애니메이션을 넣었습니다.

### 사전등록과 조회

- 진행 중인 학술행사 목록에 행사일, 장소, 사전등록 기간을 표시했습니다.
- 사전등록 신청 폼 UI에 필수값 유효성 검사와 제출 처리를 구현했습니다.
- 비회원 사전등록 조회 화면에서 연도·행사를 고르고 이름·이메일·비밀번호를 입력해 등록내역을 출력하도록 만들고, 비밀번호 찾기/변경 화면을 작업했습니다.

### 행사 일정과 회원 화면

- 국내외 학술행사 캘린더에 목록/월별 보기와 엑셀 다운로드를 구현하고 지난 학술행사 검색 화면을 만들었습니다.
- 보도자료·일반공지사항 게시판의 목록, 상세, 검색 화면을 작업했습니다.
- 제출서류를 안내하는 회원가입 안내, 로그인, 이메일·이름으로 찾는 아이디/비밀번호 찾기 화면을 만들고 회원 전용 메뉴의 접근을 처리했습니다.
