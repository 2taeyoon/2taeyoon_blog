
## Overview

PrintGuard-AI는 인쇄소에 PDF를 전달하기 전에 사용자가 직접 사전 검수할 수 있도록 만든 웹 애플리케이션입니다. 폰트 누락, 도련 부족, 이미지 해상도 저하 등의 문제를 미리 확인할 수 있으며, 선택한 종이에 인쇄했을 때 발생할 수 있는 색상 차이도 수치와 시각화 지도로 보여 줍니다.

검사 방식은 두 가지로 구성됩니다. **바로 검사**는 별도의 서버를 거치지 않고 브라우저 내부에서 모든 검사를 수행하므로 파일이 외부로 전송되지 않습니다. **에이전트 검사**는 9개의 AI 에이전트가 각자의 역할에 따라 작업을 분담하며, 작업 과정과 담당 에이전트의 활동 내역까지 기록으로 확인할 수 있습니다.

기획부터 UI, 검사 및 계산 엔진, 에이전트 서버, 배포까지 전 과정을 직접 개발한 개인 프로젝트입니다.

## Work

### PDF 검수

- 판형, 도련, 폰트 포함 여부, 이미지 해상도, 색 공간, 안전 여백 등을 검사하고 문제가 발견된 위치를 PDF 페이지 위에 표시합니다.
- 반복되는 단어, '율/률' 표기, 동일한 항목에 서로 다른 숫자가 사용된 경우 등 문구상의 오류도 함께 탐지합니다.
- 저해상도 이미지에는 필요한 원본 이미지의 최소 픽셀 크기와 현재 이미지로 인쇄할 수 있는 최대 가로 크기를 수치로 표시합니다. 이를 통해 사용자가 원본 파일을 수정할 때 필요한 조치를 쉽게 판단할 수 있습니다.

### 인쇄 사고 검사

- PDF 페이지의 콘텐츠 스트림을 직접 분석해 인쇄소에서 자주 발생하는 문제를 탐지합니다. 작은 글자의 리치 블랙, 총 잉크량 초과, 흰색 오버프린트, 지나치게 얇은 선, 이름만 다른 별색 등이 주요 검사 대상입니다.
- pdf.js는 화면에 PDF를 렌더링하기 위해 CMYK 색상을 RGB로 변환합니다. 따라서 화면 렌더링 결과만으로는 확인하기 어려운 문제를 찾아내기 위해 PDF 내부의 원본 색상 연산자를 별도로 분석합니다.
- 도련, 최소 해상도, 잉크량 제한, PDF/X 등 인쇄소의 작업 기준을 인쇄 방식별 프리셋으로 선택할 수 있습니다. 납품처별 기준에 맞게 설정을 수정하고 저장해 재사용하는 것도 가능합니다.

### 인쇄 색 차이 예측

- PDF 내부의 RGB 이미지를 종이별 CMYK ICC 프로파일로 변환하고, ΔE2000 색차와 총 잉크량을 계산해 색상 차이 지도로 시각화합니다. 색상 변환에는 lcms-wasm을 사용합니다.
- 실제 종이의 흰색을 측정한 Lab 값을 입력하면 해당 종이의 바탕색을 반영해 색상 차이를 다시 계산합니다.
- 기본 종이 종류 35종에 국내 제지사 브랜드 종이 454종을 추가해 총 489종의 종이를 선택할 수 있습니다.

### 에이전트 9개 협업 (A2A)

- 총괄, 안전 관문, 사전 검사, 색상 분석, 인쇄 가이드, 종이·위험도 분석, 교정, 보고서 작성, 원본 수정 등 총 9개의 에이전트가 A2A 방식으로 작업을 분담하고 결과를 주고받습니다.
- 외부 요청을 받는 창구는 총괄 에이전트 하나로 제한했습니다. 상태를 변경하는 모든 작업은 안전 관문의 등급 판단을 거치며, 검증에 실패하거나 권한이 확인되지 않으면 작업을 차단하는 Fail-Closed 방식으로 설계했습니다.
- 화면에서 에이전트별 작업 소요 시간과 의뢰 진행 상황을 추적할 수 있으며, 에이전트 간 주고받은 소통 기록도 확인할 수 있습니다.
- MCP 서버를 통해 13개의 도구를 제공하므로 Claude나 Cursor에서도 PDF 검수와 관련 문서 작성을 활용할 수 있습니다.

### 교정과 인디자인 원본 수정

- 맞춤법과 띄어쓰기는 규칙 기반 검사와 형태소 분석기(Kiwi)를 활용해 탐지합니다. 필요하면 Claude를 추가해 검사 정확도를 높일 수 있습니다.
- 문서 60개로 구성한 합성 평가 데이터셋에서 LLM을 결합한 방식은 재현율 99.2%, 정밀도 98.1%를 기록했습니다.
- IDML 형식의 편집 파일을 전달하면 교정 결과를 원본에 직접 반영할 수 있습니다. 글상자를 안전 여백 안으로 이동하거나 PDF/X-4 형식으로 내보내는 작업도 지원합니다.
- 교정 결과는 자동으로 수정하지 않고 제안 형태로 제공합니다. 실제 원본 파일에 반영하는 작업은 반드시 사용자의 승인을 거친 후 실행됩니다.

### 인쇄 가이드 검색과 인쇄소 지도

- multilingual-e5-small(int8 ONNX) 임베딩 모델과 BM25를 결합한 검색 방식을 사용합니다. AI가 답변을 임의로 생성하는 대신 관련 인쇄 가이드의 원문을 찾아 제공합니다.
- 브라우저에서는 Transformers.js를, 서버에서는 ONNX Runtime을 사용하며 양쪽 환경에서 동일한 모델 파일을 활용합니다.
- 행정안전부의 인쇄사 인허가 데이터 17,082곳을 Leaflet 기반 지도에 표시하고, 구글 지도와 연동해 위치를 확인할 수 있도록 구현했습니다.

### 배포

- 프론트엔드는 Vercel에 배포하고, 상시 실행이 필요한 에이전트 서버는 개인 PC에서 운영합니다. Cloudflare 터널을 연결해 외부에서도 접근할 수 있는 고정 주소를 구성했습니다.
- 로그인은 선택 사항입니다. 로그인하지 않아도 모든 검수 기능을 사용할 수 있으며, 구글 계정으로 로그인하면 기존에 진행한 검수 내역을 계정으로 가져올 수 있습니다.
