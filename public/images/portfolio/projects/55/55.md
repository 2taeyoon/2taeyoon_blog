## Overview

대한정신분석학회(한국정신분석연구원)의 학술대회, 수련과정, 클리닉 정보를 국문/영문으로 제공하는 공식 홈페이지입니다. 운영 중인 사이트에서 문의 폼, 클리닉 검색, 수련 신청 등 화면을 유지보수했습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 대한정신분석학회 홈페이지(국문/영문)의 퍼블리싱과 프론트엔드 작업을 진행했습니다.

### 메인 화면
- 메인 비주얼, 새소식/공지사항 최신글, 정신분석 안내 카드, 클리닉 검색 영역, bxSlider 하단 배너 슬라이더를 작업했습니다.

### 문의와 클리닉 검색
- 분류 선택, 성함·이메일·내용 입력, 파일 첨부, 자동입력방지 문자와 유효성 검사를 갖춘 문의사항 폼을 구현했습니다.
- 지역 셀렉트와 치료자 성함·클리닉명 검색, 리스트 정렬이 가능한 클리닉 찾기 화면을 작업했습니다.

### 수련과정과 학술대회
- 커리큘럼 표가 있는 정신분석적 정신치료 수련과정 안내와 수련 신청·신청확인 화면을 구현했습니다.
- 학술대회 목록/상세와 필수값 유효성 검사·개인정보 동의를 포함한 사전등록 신청 폼, 확인 화면을 작업했습니다.
- 마이페이지 결제내역(영수증) 화면을 구현했습니다.

### 게시판과 학회 정보
- 새소식·자료실·뉴스레터·최신 회원서적 게시판의 목록/상세/검색을 작업했습니다.
- 학술활동·증례토론·회원공간 게시판은 회원 전용 메뉴의 접근 처리를 적용했습니다.
- 학회소개·정관·연혁·임원진·사무국 지도 페이지와 회원가입 약관 동의·로그인 화면을 구성했습니다.
