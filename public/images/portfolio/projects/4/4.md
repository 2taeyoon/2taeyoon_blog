## Overview

hivu는 기업과 인플루언서를 연결해 지역 기반 체험형 마케팅 캠페인을 진행하는 플랫폼입니다. 실시간 리뷰, 참여형 이벤트, 지도 기반 캠페인 검색, 리뷰 통계 기능에 더해 신규·추천 캠페인 같은 마케팅 콘텐츠와 슈퍼리뷰어 전용 페이지, 사용자 커뮤니티가 들어 있습니다.

## Work

이미 운영 중인 서비스에 퍼블리싱으로 참여했습니다. 프론트엔드와 백엔드 로직은 작업 범위가 아니었고 화면 마크업과 스타일링을 맡았습니다.

### 마크업과 스타일링

- HTML 구조와 CSS 스타일링 일부를 작업했습니다.
- 캠페인 상세 화면과 메인 UI 일부를 마크업했습니다.
- Clipboard 버튼의 위치와 스타일을 잡았습니다.

### 통계 차트

- ApexCharts로 통계 차트를 마크업하고 퍼블리싱했습니다.
