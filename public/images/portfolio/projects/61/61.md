## Overview

메드소프트 운영팀이 디자인과 퍼블리싱 작업을 정리해 두는 아카이브 사이트입니다. 학회 사이트 레이아웃을 기반으로 공통 레이아웃과 텍스트 효과 예제 등을 퍼블리싱했습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 운영팀 아카이브 사이트의 공통 레이아웃과 예제 페이지를 작업했습니다.

### 공통 레이아웃
- 공지 문구 영역, 로그인/회원가입, KO/EN 언어 전환이 있는 공통 헤더와 GNB·햄버거 전체메뉴를 구성했습니다.
- TOP 버튼과 개인정보처리방침·이용약관·사이트맵 링크가 있는 푸터를 작업했습니다.

### 퀵메뉴와 예제 페이지
- 문의·학술대회·자료실·행사일정 우측 플로팅 퀵메뉴와 대표전화, SNS 링크 영역을 구현했습니다.
- 웹진 페이지에 헤더 텍스트 효과 예제와 텍스트 애니메이션 속도 조절 인터랙션을 퍼블리싱했습니다.
