## Overview

대한탈장학회의 학술대회, 행사일정, 탈장 관련 정보를 제공하는 공식 홈페이지입니다. 운영 중인 사이트에서 사전등록 폼과 학술행사 캘린더, 게시판 화면을 유지보수했습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 대한탈장학회 홈페이지의 학술대회 안내와 게시판 화면을 수정했습니다.

### 학술대회와 일정
- 진행 중인 학술대회 사전등록 안내와 국내외 학술행사 일정을 업데이트했습니다.
- 사전등록 폼의 입력 항목을 변경하고 유효성 검사를 보완했습니다.

### 메인과 게시판
- 메인 비주얼 슬라이드와 후원사 배너를 교체 등록했습니다.
- 행사 갤러리·탈장 상식 Q&A 게시판의 목록·상세 화면 오류를 수정했습니다.
