## Overview

대한이비인후과의사회의 공식 홈페이지입니다. 회원가입과 이비인후과 병원 찾기, 학술행사 사전등록, 동호회 가입신청, 귀·코·목 질환정보를 제공합니다.

## Work

운영 중인 사이트의 유지보수로 참여해 대한이비인후과의사회 홈페이지의 콘텐츠와 폼 화면을 수정했습니다.

### 행사와 회원가입
- 학술행사 사전등록 안내를 일정에 맞춰 업데이트했습니다.
- 회원가입 폼의 입력 항목을 변경하고 유효성 검사를 보완했습니다.

### 메인과 게시판
- 메인 배너 슬라이드를 교체 등록하고 귀·코·목 질환정보 페이지 내용을 수정했습니다.
- 뉴스브리핑 게시판의 목록·상세 화면 오류와 반응형 레이아웃 깨짐을 수정했습니다.
