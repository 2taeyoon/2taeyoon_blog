## Overview

한국주조공학회지의 영문 홈페이지로, 논문 검색과 호별 논문 열람, 투고 안내를 제공합니다. 운영 중인 사이트의 유지보수로 참여해 콘텐츠 업데이트와 화면 수정을 맡았습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 한국주조공학회지 영문 홈페이지의 콘텐츠와 화면을 수정했습니다.

### 논문 열람 화면
- Current Issue와 Archive 목록의 화면 오류를 수정했습니다.
- 논문 상세 검색 결과 목록의 표시 문제를 보완했습니다.

### 학술지 안내
- Editorial board·Instruction for Authors 등 학술지 안내 페이지 내용을 업데이트했습니다.
- 메인 배너를 교체하고 모바일 메뉴의 레이아웃 깨짐을 수정했습니다.
