## Overview

AlphaBeta AI는 보건의료 데이터 분석과 연구지원 솔루션을 제공하는 기업입니다. 회사와 솔루션, 수행 프로젝트를 소개하고 분석의뢰를 온라인으로 접수할 수 있도록 반응형 홈페이지로 구축했습니다.

## Work

팀 프로젝트로 AlphaBeta AI 공식 홈페이지의 반응형 퍼블리싱과 프론트엔드 개발에 참여했습니다.

### 메인 화면과 인터랙션
- 메인 비주얼 영상·슬라이드와 연구지원 솔루션, 최근 수행 프로젝트, 뉴스 섹션을 구현했습니다.
- AOS 스크롤 애니메이션을 적용해 섹션 진입 시 콘텐츠가 자연스럽게 나타나도록 했습니다.
- GNB 드롭다운과 모바일 전체메뉴 인터랙션을 작업했습니다.

### 분석의뢰 신청 폼
- 신청유형(신규/추가) 선택, 성함·소속 기관명·직책·연락처·이메일 입력, 지원내용 체크 항목과 신청 내용 요약·상세 입력 영역을 개발했습니다.
- 다중 파일 첨부, 개인정보 처리방침 동의, 자동입력방지 코드 입력과 제출 처리 화면을 구현했습니다.
- jQuery Validate로 필수값 유효성 검사를 적용했습니다.
- 의뢰 비용 안내와 의뢰 신청 절차 안내, 기타 문의 페이지를 구성했습니다.

### 회사·포트폴리오 콘텐츠
- 미션·비전·핵심기술·연혁·CI, 대표 소개, 구성원과 자문위원, 오시는 길 지도 페이지를 퍼블리싱했습니다.
- 지식재산권·논문 목록·분야별 수행 프로젝트 포트폴리오와 솔루션 페이지를 작업했습니다.
- News 게시판 목록/상세에 검색, 목록 개수 선택, 페이지네이션을 구현했습니다.
