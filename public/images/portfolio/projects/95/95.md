## Overview

대한임상미생물학회의 국문·영문 공식 홈페이지입니다. 학술대회 사전등록·초록접수·후원 신청과 학술행사 일정, E-Learning, 연구회 소개와 회원 서비스를 제공합니다.

## Work

운영 중인 사이트의 유지보수로 참여해 학술대회 접수와 행사 화면을 중심으로 프론트엔드 작업을 했습니다.

### 메인과 학술대회 페이지
- 공지·학술행사 탭, bxSlider 배너, 주요행사일정 캘린더, 메인 로그인 박스와 GNB·모바일 메뉴를 구현했습니다.
- 초대의 글, 행사안내, 일자별 학술프로그램 탭, 초록접수 안내, 오시는 길 페이지를 퍼블리싱했습니다.

### 등록과 신청
- 사전등록, 초록접수, 후원 신청 화면에 필수값 유효성 검사를 넣고 광고·부스 단가 표를 작업했습니다.
- 이름·비밀번호로 등록을 조회하고 확인 단계로 이동하는 화면을 구현했습니다.

### 일정과 회원
- 본회/유관 필터와 연·월 선택 학술행사 일정, 역대 행사 카테고리 검색, 연도별 학술상 탭을 작업했습니다.
- 이수증 출력이 있는 E-Learning 화면을 작업하고 마이페이지와 자료실은 회원 전용 메뉴로 접근 처리했습니다.
- 회원검색, 아이디/비밀번호 찾기, 연구회 소개와 게시판 목록/검색 화면을 작업했습니다.
