## Overview

대한수면의학회 홈페이지는 인트로에서 전문가용과 일반인용 사이트로 나뉘는 반응형 공식 사이트입니다. 전문가에게는 학술행사와 학술지를, 일반인에게는 수면건강정보와 수면클리닉 찾기를 제공합니다.

## Work

운영 중인 대한수면의학회 홈페이지의 유지보수로 참여해 전문가용·일반인용 화면의 콘텐츠를 수정했습니다.

### 전문가용 학술행사
- 연수교육 사전등록 안내와 진행 중인 학술행사 목록을 일정에 맞춰 업데이트했습니다.
- 사전등록 화면의 입력 항목을 변경하고 유효성 검사를 보완했습니다.

### 일반인용 정보와 레이아웃
- 수면건강정보 콘텐츠를 수정하고 수면클리닉 찾기 화면의 표시 오류를 수정했습니다.
- 메인 슬라이드·팝업을 교체하고 반응형 레이아웃 깨짐을 수정했습니다.
