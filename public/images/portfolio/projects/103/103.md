## Overview

원주연세의료원 의과학연구처와 미래의료산학협력단의 연구지원 업무를 안내하는 홈페이지입니다. 운영 중인 사이트에서 간접비 계산기, 특허 검색, 업무 안내와 게시판 화면을 유지보수했습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 의과학연구처 홈페이지의 업무 안내와 게시판 화면을 수정했습니다.

### 업무 안내 페이지
- 연구진흥사업·연구비관리 등 업무 안내 페이지와 담당업무 연락처 표를 변경 사항에 맞춰 업데이트했습니다.
- 간접비 계산기의 숫자 입력 검사와 계산 결과 표시 오류를 수정하고, 모바일에서 입력 영역이 깨지지 않도록 레이아웃을 보완했습니다.

### 메인과 게시판
- 메인 배너 슬라이드를 교체 등록했습니다.
- 공지·규정류·서식/참고자료 게시판의 목록·상세 화면 오류와 반응형 레이아웃 깨짐을 수정했습니다.
