## Overview

한국탄소나노산업협회·연구조합 국문/영문 홈페이지의 유지보수로 참여해 퍼블리싱과 프론트엔드 작업을 진행했습니다. 사업별 탭 콘텐츠와 분류 필터가 있는 게시판, 회원사 안내 화면 등을 다뤘습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 한국탄소나노산업협회 홈페이지의 화면과 기능을 작업했습니다.

### 메인과 내비게이션
- 메인 퀵메뉴와 bxSlider 다중 롤링 배너 슬라이드를 구현했습니다.
- 공지/소식 최신글과 관련사이트 배너 롤링 영역을 작업했습니다.
- 협회/조합소개·주요사업·알림마당·회원사 GNB 드롭다운과 모바일 전체메뉴 인터랙션을 구현했습니다.

### 사업과 소개 페이지
- 경영전략실·산업진흥실·기업육성실·대전센터 사업별 탭 콘텐츠 페이지를 구성했습니다.
- 설립개요·미션&비전·연혁 탭과 조직도 연락처 표를 작업했습니다.

### 게시판과 회원사
- 공지사항·협회/조합뉴스·회원사 소식·산업 동향·자료실·보도자료 게시판에 목록 개수 선택, 분류 필터, 제목 검색, 페이지네이션을 적용했습니다.
- 가입절차·회비 표가 있는 회원사 가입안내와 회원사 혜택, 임원사/회원사 현황 화면을 구성했습니다.
- 단체메일 수신 동의를 필수로 선택하는 회원가입과 로그인·아이디/비밀번호 찾기, 영문 페이지, 오시는 길 지도를 작업했습니다.
