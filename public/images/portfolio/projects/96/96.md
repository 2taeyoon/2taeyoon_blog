## Overview

한국탄소나노산업협회·연구조합 국문/영문 홈페이지의 유지보수로 참여해 콘텐츠 업데이트와 화면 수정을 맡았습니다. 사업별 탭 콘텐츠와 분류 필터가 있는 게시판, 회원사 안내 화면 등을 다뤘습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 한국탄소나노산업협회 국문/영문 홈페이지의 콘텐츠와 게시판 화면을 수정했습니다.

### 사업과 소개 페이지
- 주요사업 탭 콘텐츠와 조직도 연락처 표를 변경 사항에 맞춰 업데이트했습니다.
- 메인 롤링 배너와 관련사이트 배너를 교체 등록했습니다.

### 게시판과 레이아웃
- 협회/조합뉴스·산업 동향 게시판의 목록·상세 화면 오류를 수정했습니다.
- 모바일 전체메뉴와 서브페이지의 반응형 레이아웃 깨짐을 수정했습니다.
