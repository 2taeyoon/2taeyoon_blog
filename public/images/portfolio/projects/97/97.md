## Overview

아시아태평양감염재단(APFID)의 산하 프로그램과 학술대회를 영문으로 소개하는 공식 홈페이지입니다. 운영 중인 사이트에서 메인 탭 비주얼과 소개·데이터 표 페이지, 게시판 화면을 유지보수했습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 아시아태평양감염재단 영문 홈페이지의 콘텐츠와 화면을 수정했습니다.

### 소개·데이터 페이지
- ABB Culture Collections, IDRI Members 등 데이터 표 페이지 내용을 업데이트했습니다.
- 메인 팝업존과 비주얼 탭 이미지를 교체 등록했습니다.

### 게시판과 레이아웃
- APFID News·PHOTOS OF ISAAR 게시판의 목록·상세 화면 오류를 수정했습니다.
- 데이터 표 페이지와 모바일 메뉴의 반응형 레이아웃 깨짐을 수정했습니다.
