## Overview

한국환경보건학회가 매년 여는 가을 정기학술대회의 행사 전용 홈페이지입니다. 사전등록과 초록접수, 후원 안내, 숙박과 행사장 정보를 제공하고, 친환경 행사를 지향하는 '불편한 학회' 체크리스트와 택시공유 안내도 담았습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 학술대회 행사 사이트의 반응형 퍼블리싱과 프론트엔드 작업을 했습니다.

### 메인 화면

- bxSlider 메인 비주얼과 공지 최신글을 구현했습니다.
- 등록·초록·후원 마감일을 보여 주는 DUE DATES, 택시공유(car pool) 오픈채팅, 친환경 행사 안내 영역을 작업했습니다.

### 사전등록

- 회원/비회원/단체 등록을 고르는 화면과 비회원·단체 대표자 입력 폼을 만들었습니다.
- 이름·이메일·연락처·비밀번호 확인 입력에 유효성 검사를 넣고 비밀번호 이메일 전송을 연결했습니다.
- 비회원·단체 사전등록 확인 조회 폼과 등록방법·서류 다운로드가 있는 등록안내 페이지를 작업했습니다.

### 초록접수와 부대 행사

- 비회원 초록 등록/확인 화면과 초록양식 다운로드를 구현하고, 접수기간이 아닐 때 안내를 띄웠습니다. 초록접수 확인은 회원 전용 메뉴로 접근을 처리했습니다.
- 후원안내(공문 다운로드, 후원업체 등록·후원 조회 버튼), 펍데이 신청 폼, 숙박·행사장·여행코스 페이지를 작업했습니다.
- '불편한 학회' 체크리스트 페이지를 만들고 rwdImageMaps로 반응형 이미지맵을 적용했습니다.
