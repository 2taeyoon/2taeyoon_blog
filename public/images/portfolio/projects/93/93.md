## Overview

대한리프팅학회 홈페이지는 학술대회와 행사일정, 회원 게시판을 담은 반응형 공식 사이트입니다. 학술대회 사전등록과 연자접수를 사이트에서 받습니다.

## Work

운영 중인 대한리프팅학회 홈페이지의 유지보수로 참여해 학술대회 안내와 게시판 화면을 수정했습니다.

### 학술대회 안내
- 등록 중인 행사와 상세 안내를 학술대회 일정에 맞춰 업데이트했습니다.
- 사전등록·연자접수 폼의 입력 항목을 변경하고 유효성 검사를 보완했습니다.

### 메인과 게시판
- 메인 비주얼 슬라이드와 레이어 팝업을 교체 등록했습니다.
- 공지사항·갤러리 게시판의 목록·상세 화면 오류와 모바일 전체메뉴의 레이아웃 깨짐을 수정했습니다.
