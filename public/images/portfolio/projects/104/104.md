## Overview

한국전자파학회는 전자파 분야의 학회입니다. 국문/영문 홈페이지에서 행사 안내와 사전등록, 21개 연구회와 9개 지부 소개를 제공하고, 사무국 문의와 계산서 신청, 회의실 예약 같은 회원 서비스를 운영합니다.

## Work

운영 중인 사이트의 유지보수로 참여해 학회 홈페이지(국문/영문)의 반응형 퍼블리싱과 프론트엔드 작업을 했습니다.

### 메인과 내비게이션

- Owl Carousel 메인 비주얼, 공지 탭, 행사 롤링, 간행물, 행사일정 캘린더, 특별회원사 롤링 영역을 작업했습니다.
- GNB 드롭다운과 모바일 전체메뉴를 구현했습니다.

### 행사와 신청 폼

- 연도와 제목/내용으로 검색하는 행사안내 목록과 파일 다운로드·논문접수·사전등록 탭이 있는 상세 화면을 만들었습니다.
- 사전등록 신청과 비회원 행사 등록조회 화면을 작업했습니다.
- 사무국 문의 폼에 문의 분류 선택, 이름·연락처·이메일·내용 입력, 체크박스 선택, 개인정보 동의, 자동등록 방지 문자를 넣고 계산서 신청 화면을 구현했습니다.

### 회의실 예약과 연구회

- 월별 달력을 이전/다음으로 넘기며 날짜별 예약 현황을 보고 예약을 신청하는 회의실 예약 화면을 구현했습니다.
- 연구회 21개와 지부 9개 소개 페이지에 위원장 정보와 연구회별 행사 일정 미니 캘린더를 넣었습니다.

### 게시판과 회원 화면

- 공지·학회뉴스·학생기자단·FAQ·구인공고·언론보도 등 게시판의 목록과 검색 화면을 작업했습니다.
- 약관 동의, 가입신청서, 완료, 회비납부로 이어지는 회원가입 단계와 로그인, 회원검색, 종신회원 명단 화면을 만들고 회비납부·My Page는 회원 전용 메뉴로 접근을 처리했습니다.
