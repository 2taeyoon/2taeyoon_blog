## Overview

대한생물정신의학회 공식 홈페이지의 유지보수로 참여해 퍼블리싱과 프론트엔드 작업을 진행했습니다. 학술행사 일정 보기 전환, 회원/비회원 사전등록·초록접수, 지난학술대회 검색 화면 등을 다뤘습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 대한생물정신의학회 홈페이지의 화면과 기능을 작업했습니다.

### 메인 화면
- 메인 배너 슬라이드와 하단 배너 슬라이드를 Swiper·bxSlider로 구현했습니다.
- 공지/학술행사/갤러리 탭 영역과 레이어 팝업을 작업했습니다.

### 학술행사
- 학술행사 일정을 목록형·월별형·달력형으로 전환하고 연/월 이동과 엑셀 다운로드를 구현했습니다.
- 학술대회 사전등록·초록접수 화면에 회원/비회원 선택을 구성했습니다.
- 비회원 이름·이메일·비밀번호 입력에 유효성 검사를 적용하고 비밀번호 이메일 전송 화면을 작업했습니다.
- 지난학술대회를 연·월 필터로 검색하고 PDF로 내려받게 구현했습니다.

### 게시판과 회원
- 공지사항·학회 사진첩·초록집자료실·뉴스레터 게시판의 목록/상세/검색·페이지네이션을 작업했습니다.
- 플라자 게시판에 자유/연구자/이벤트 카테고리 필터를 적용했습니다.
- 학회소개·연혁·임원진·학회지·윤리규정·투고형식점검표 페이지와 약관동의 회원가입·아이디/비밀번호 찾기 화면을 구성하고, 회원 명부는 회원 전용 메뉴의 접근 처리를 적용했습니다.
