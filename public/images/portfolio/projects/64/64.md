## Overview

부산광역시치과의사회의 공식 홈페이지로, 세미나 일정과 회원 검색, 부치신문, BDEX 행사 정보를 제공합니다. 운영 중인 사이트의 유지보수로 참여해 반응형 퍼블리싱과 프론트엔드 작업을 했습니다. 세미나캘린더와 검색·인증 화면을 중심으로 작업했습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 부산광역시치과의사회 홈페이지의 프론트엔드 작업을 했습니다.

### 메인
- 메인 배너 슬라이드, 이사회 일정 월간 캘린더, 회원전용 주요 메뉴, 최신글, 유튜브 영역을 구현했습니다.
- 하단 배너 롤링을 작업했습니다.

### 세미나와 행사 등록
- 세미나캘린더를 월별/목록으로 전환하고 연/월 이동, 엑셀 다운로드를 구현했습니다.
- 연·월 필터로 찾는 지난행사보기 검색을 작업했습니다.
- 사전등록/사전등록확인 행사등록안내와 회원/비회원 등록 입력 화면을 구성했습니다.
- 이름, 면허번호, 휴대폰 번호를 입력해 조회하는 강연영상 접근 인증 폼을 구현했습니다.

### 검색과 게시판
- 구별 선택과 통합검색이 있는 우수회원치과검색, 회원주소록 검색 화면을 작업했습니다.
- 종합·학술·치재·보험·칼럼 등 부치신문 카테고리 게시판의 목록/상세/검색과 BDEX 공지·현장사진·포스터세션 갤러리형 게시판을 구현했습니다.
- 개인/병원/기업 회원 유형별 가입안내, 약관동의, 고충처리센터 안내, Google 지도 오시는 길을 작업했고 회원 게시판·회비납부·고충상담은 회원 전용 메뉴로 접근 처리했습니다.
