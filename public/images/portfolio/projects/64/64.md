## Overview

부산광역시치과의사회의 공식 홈페이지로, 세미나 일정과 회원 검색, 부치신문, BDEX 행사 정보를 제공합니다. 운영 중인 사이트의 유지보수로 참여해 콘텐츠 업데이트와 화면 수정을 맡았습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 부산광역시치과의사회 홈페이지의 콘텐츠와 화면을 수정했습니다.

### 세미나와 행사 안내
- 세미나캘린더와 BDEX 행사 안내 내용을 일정에 맞춰 업데이트했습니다.
- 사전등록 입력 화면의 항목을 변경하고 유효성 검사를 보완했습니다.

### 메인과 게시판
- 메인 배너 슬라이드와 하단 배너를 교체 등록했습니다.
- 부치신문 카테고리 게시판의 목록·상세 화면 오류와 반응형 레이아웃 깨짐을 수정했습니다.
