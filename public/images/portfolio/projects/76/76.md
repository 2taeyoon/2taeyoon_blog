## Overview

심혈관연구원은 심혈관 분야 연구와 SCI·CTO 같은 학술대회를 운영하는 기관입니다. 운영 중인 사이트의 유지보수로 참여해 콘텐츠 업데이트와 화면 수정을 맡았습니다.

## Work

운영 중인 사이트의 유지보수로 참여해 심혈관연구원 홈페이지의 학술대회 안내와 화면을 수정했습니다.

### 학술대회 안내
- SCI·CTO 학술대회 페이지의 Overview·프로그램·등록 안내를 행사 일정에 맞춰 업데이트했습니다.
- 우수논문 공모 안내를 수정하고 연도별 Program Book 자료를 추가했습니다.

### 메인과 게시판
- 메인 하단 팝업과 이달의 행사일정 내용을 교체했습니다.
- 강의 동영상·건강강좌 게시판의 목록·상세 화면 오류와 반응형 레이아웃 깨짐을 수정했습니다.
