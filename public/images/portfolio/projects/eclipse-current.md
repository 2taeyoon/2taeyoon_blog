## Overview

Eclipse Current는 어두운 인터페이스에서 색, 선, 여백만으로 상태와 흐름을 표현하는 디자인 시스템 프로젝트입니다.

## Challenge

테마 색상이 바뀌어도 텍스트 대비와 컴포넌트의 역할이 일관되게 유지되는 확장 가능한 규칙이 필요했습니다.

## Approach

- 의미를 기준으로 색상 토큰과 표면 토큰 정의
- 컴포넌트 내부의 고정 색상을 공통 변수로 교체
- 새로고침과 페이지 이동 사이의 사용자 설정 유지

## Key Features

### Shared theme state

여러 페이지가 동일한 상태를 구독해 색상 설정이 경로와 관계없이 하나의 경험으로 이어집니다.

### Token-based UI

컴포넌트가 특정 색상 대신 역할 기반 변수를 사용해 새로운 테마를 추가할 때 수정 범위를 줄였습니다.

## Outcome

화면 단위의 스타일링을 넘어 상태와 토큰이 함께 동작하는 유지보수 가능한 테마 기반을 구축했습니다.
