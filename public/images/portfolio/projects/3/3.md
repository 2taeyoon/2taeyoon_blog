## Overview

MyDays는 기념일이나 생일처럼 기억해야 할 날짜를 한곳에 모아 두는 웹 애플리케이션입니다. 날짜를 등록하면 디데이와 나이 같은 정보가 바로 계산되어 나오고 데이터는 실시간으로 갱신됩니다. 회원으로 가입해 쓸 수 있고 앱처럼 설치해서 쓸 수도 있습니다.

## Work

### 날짜와 디데이 관리

- 날짜를 선택하면 디데이가 표시됩니다.
- 기념일, 생일 같은 이벤트를 추가하고 관리할 수 있습니다.
- 나이처럼 날짜로 계산되는 정보도 함께 보여 줍니다.

### 화면 구성

- 항목 사이는 Swiper로 넘겨 봅니다.
- 날짜 선택 화면은 jQuery UI로 구성했습니다.

### 회원과 데이터 관리

- Firebase로 이메일 회원가입과 로그인을 구현했습니다.
- 관리자 기능도 Firebase로 붙였습니다. 관리자는 콘텐츠와 사용자 활동을 관리하고 디데이 이벤트를 추가합니다.

### PWA

- Service Worker를 적용해 설치형 앱처럼 다시 열 수 있게 했습니다.
