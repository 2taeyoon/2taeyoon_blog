## Overview

MyDays는 기념일, 생일, 나이처럼 기억해야 할 날짜를 모아 두고 디데이를 확인하는 웹 앱입니다. 날짜를 고르고 이벤트를 추가한 뒤, Swiper로 항목을 넘겨 보며 남은 날을 확인합니다.

## Approach

- PWA와 Service Worker로 앱처럼 다시 열 수 있게 구성
- Firebase 이메일 가입과 로그인으로 기록을 계정에 연결
- jQuery UI와 Swiper로 날짜 선택과 목록 이동을 나눔
